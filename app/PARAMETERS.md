# v1.0.4 参数与研究口径

v1.0.4 仅调整界面布局，研究参数和执行规则沿用 v1.0.3。

独立模拟工作流采用 `agent_mlp_sim_v1`；无账户分析与扫描另用方法身份。下列值是有界研究默认值，不能据此宣称可靠收益；最终每份结果保存实际参数、数据和模型身份。

| 项目 | 默认/边界 | 含义 |
|---|---|---|
| Kronos | 128根输入、5交易日、预览8路径/研究32路径 | 本地冻结权重，温度0.8、top-p0.9、固定种子42 |
| 候选观察 | 3交易日，可比较1日 | 持仓与候选共享逐日队列，缓存也占逻辑额度 |
| 模拟账户 | 初始100万元、单股最多20% | 资金、整手、风险及费用会使实际仓位低于目标 |
| 均线 MLP | `ma_trend_v1` 20项 | MA偏离、斜率、排列、间距、收益、波动和回撤；同步训练同输入L2 |
| 混合 MLP 对照 | `mixed_v1` A 34项 / B 44项 | 保留旧输入身份；不重命名成均线模型 |
| 组合扫描 | 每批200次预测/300秒 | 完整沪深人口，延后项保留；显式续批生成新结果 |
| 学习预算 | 最多10分钟、20股、10万成熟行 | 不自动训练Kronos；候选不自动晋升 |
| 试验预算 | 6个MLP、2组Kronos、6组策略 | 预登记，不无限择优 |
| B历史观察 | 每批200次/300秒，累计2000次/10批 | 冻结人口；失败、无效、延后均保留 |
| 补结构 | 默认20股/300秒、1原生worker | 预览缺口；复用/追加/受影响股票重建 |
| 留存 | 预览7天、无引用缓存8GiB | 保存账户和必要引用不按TTL删除 |

结构分析和扫描用 `analysis_method` 固定方法，并记录实际 `score_model_id`。均线模型和同输入 L2 使用同一个候选中的配对产物。单股默认1次预测；时间上限允许10至1800秒。预算从入口及身份核验开始；它限制新增计算，必要的退出、核验和保存仍须完成，实际超出量另行记录。预测路径不足质量门槛时显示不可用，可显式改用32路径，不自动降低门槛。详细接口、冻结身份和清理说明见 [均线组合方法与任务维护](my_strategy/docs/ma_methods_and_task_maintenance_20261015.md)。

## 显示与账户草稿

预测、模拟账户和模型学习的股票池及参数各自独立。“带入分析/回测”只填写草稿，运行按钮才提交任务。已保存结果沿用原开始/截止日期、实际模型和预测参数；表单改动不把旧结果重新命名为新参数结果。

预测图的最近 30/60 根、完整窗口和显示起点只是显示范围，不是 128/256 根模型输入设置。结构主图的方法点只反映截止日有效 BUY/SELL，历史来源点单独开关。扫描与板块统计以明确选定的完整保存结果为分母；有效 WAIT 与不可用、失败、待处理不同，成员预测横截面不是板块自身预测。

## 账户检验

同频每日净值包括空仓日，夏普年化252日、无风险利率默认0；无成交或不足核验交易日不填零夏普。费用包含佣金、最低佣金、过户、交易方向相关费用与滑点，具体冻结成本模型进入账本。费用压力1/1.5/2倍必须实际回放。负股数、库存前后、计划权重和执行权重分别报告。

既有库存价格保护、组合回撤和退出规则独立于模型资格。历史候选可用于研究账户；每日影子研究要显式启用，自动纸上增仓仍需独立政策资格，前瞻认证另行验证。缺失数据不会被当作下跌或强制产生卖单。

## 高级旧参考流程

`reference_position_v1` 保留为明确的旧参考研究入口，模型参数源为 `reference_training.py:DEFAULTS`。其10日标签、方向模型、参考目标档位等不等于新模拟账户设置；风险参考上限不等于成交仓位。当前公共策略配置不指向本地私人模型，不发布训练权重。
