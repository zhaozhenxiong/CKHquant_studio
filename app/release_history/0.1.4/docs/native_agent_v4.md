# 原生多 Agent v4

此版本实施 2026-10-12 的结构、量价、高收益算法修复计划。界面默认仅画最终 B/S，点击才打开详情；威科夫原始事件由独立开关控制，包含待测试 SOS/Spring，日、周、月均保留原可知日期。历史表与弹窗使用同一份方向事实、风险通过数和当日意见。

## 判断契约

权重仍为 MA 40%、独立结构 20%、威科夫 30%、高收益质量 10%。高收益仅筛已有 BUY，不参与 SELL。缺失权重不重分配，原辅助 BS2/BS3 继续归入 MA 依赖家族。仲裁版本 `czsc_agent_consensus_v4`，训练族 `czsc_high_return_v4_native`；旧 v1/v2/v3、29 个核心源码、原模型和正式发行资产保留。

纯结构由已确认笔生产原生一买/一卖、纯二买/二卖、纯三买；原算法没有三卖，未构造镜像。最新形成中中枢不会遮蔽之前仍有效的确认中枢。同一模式只有首次确认事实；持续结构支持另存。原事实首次可知日、锚点和身份固定，风险拒绝不能刷新年龄。仍有效的机会首次取得风险资格时仅生成一次独立“资格激活”，同时保留原确认日期和原参考价。

结构资格核对整个实际依赖区间与独立核验交易日历，包括很久以前的笔和中枢；辅助结构同时检查五笔与34日均线依赖。缺交易日、缺核验日历或形成中模式保留原始事实和拒绝原因，但不取得方向资格。股票自身有行情的日期不能充当完整交易日历。缺口早于首个实际依赖行情时不会误判；未来日历延长不能改变已经发生的历史事实。

威科夫有两个独立渠道：当日 OHLCV 因果连续规则分，以及未失效原事件的衰减支持。每个需求/供给事件保存原观察时间、专属边界、风险止损和当前快照。确认事件或当日连续强度达到门槛可支持同一方向；合格的相反证据构成同源冲突，整个 W 家族只计一次 30%。待测试事件不投确认票，失效事件不复活。规则分不是获利概率。

MA 长期趋势、短期战术转弱、入场概率分开。短期交叉转弱不直接产生长期失效 SELL，也不使用 `1-p_buy` 推导卖出。每日概率可供研究观察；只有相同新候选并集、风险资格和模型目标范围内的概率才取得 40% 入场票。

原始候选是否有效由原模式、当前状态、首次可知时间和失效边界决定，不由该来源的 ML 概率决定。例如 MA 产生有效候选，但 MA 概率未过门槛时，其40%可以不投票；结构、量价和高收益仍共同评估该候选。其他专家的持续意见只能支持已存在的真实新候选，不能自行制造买点。

高收益状态有七种：无候选、风险阻止未评分、输入不合格、缺兼容模型、已评分未过门槛、已评分通过、真实身份错误。`null` 不补为 0。先判断是否实际评分，已有评分才核验模型身份、日期、目标、候选和风险哈希。质量权重 10% 与概率门槛 0.1 是不同参数。

## 风险、标签与实际交易

新风险政策保留 15% 最大初始止损距离。MA 边界使用 `max(前20日低点, 当日收盘 - 2×前14日ATR)`，再减前 ATR 的 0.25 缓冲；纯结构与 W 使用原事件冻结的风险止损。ATR、量能基准均排除当日。另行训练的 `legacy_trailing20_v4_control` 保留前20日低点风险对照；不同风险哈希不可借用模型。

新 MA 20项入场输入覆盖风险合格的新候选并集；独立退出输入为20项MA加10项已发生持仓状态。训练顺序为原始并集规则 bootstrap → 12个季度独立退出头 → 持仓固定信号时严格更早的退出头，重建正收益入场标签 → 12个入场头 → 前向MA概率 → 新L2标签和模型。无更早退出头的整段持仓明确使用规则v0，不在持仓中途升级。

L2输入98项（旧94项加4项原生结构/连续量价支持），持仓输入108项。新目标、schema、原生政策、风险、来源、代码、日历和实际完成时间均单独绑定。标签来自实际Broker费用后完整清仓回合；高收益仍要求至少8%且至少2R。拒单、未完成持仓、未成熟配对分支不作为负样本。

图表B/S是综合方向研究点。实际入口使用最终B与同日原风险计划；标签冻结续持与验收出口均使用原始并集退出、真实硬止损、60核验交易日上限和信号时固定的MA退出头。图表S与实际清仓分开保存；不拿图表理论库存替代真实Broker。成交在下一核验开盘，遵守T+1、费用、数量、缺行情与停牌拒单。

## 运行与调参

仲裁展示参数位于 `configs/czsc_agent_consensus.json`；权重、质量门槛和1/3/5根证据窗口可在新请求调整，保存结果仍按其原版本和配置回放。候选、原生规则、风险或续持政策变化须生成新标签/模型；不能仅改参数并沿用旧身份。

显式离线训练：

```sh
PYTHONPATH=app .venv/bin/python -m my_strategy.scripts.train_native_v4 --cohort <冻结股票池JSON> --cpu-workers 4 --device cpu
```

真实Broker验收：

```sh
PYTHONPATH=app .venv/bin/python -m my_strategy.scripts.validate_native_v4 --model-run-id <新模型运行ID> --cohort training --cpu-workers 4
```

本轮先核验002436.SZ、600519.SH、000333.SZ，再使用3个对照加57个固定种子股票身份哈希选出的60股主板样本。选择不读取未来收益。四个已读季度与2026YTD仅作开发诊断，正常和双倍滑点均保留实际账本。原始行情截止2026-10-09；模型冻结特征源截止2026-10-08。未复权、历史ST及完整股票池边界继续披露。正式活动别名与发布事务保持不变，冻结后至少3个480核验交易日独立窗口尚未成熟，状态为pending。

新版图表和扫描使用原生 v4 模型。旧版任意账户回测、持仓评分和 forward-status 接口保留旧版本契约，不接收 v4 模型冒充旧模型；v4 的实际账户验收使用上述独立 CLI，并保存完整账本、持仓快照和拒单。网页模型状态会披露这些入口的能力范围。

## 评分及卖点口径仍需区分

当前MA概率目标为“按冻结退出政策形成完整费用后正收益回合”。它不是独立的未来趋势分类概率。仲裁仍采用55%门槛投票：1月21日46.58%的已评分概率贡献0分，结构20分、量价30分与高收益质量10分共同形成B；10月9日66.27%是没有新候选的范围外研究分。概率存在、趋势意见和贡献0分应分别显示，不能称为没有评分。若改为未来趋势上涨/下跌/中性概率及连续加权贡献，需要独立的预测周期、标签、模型及校准，不能仅重命名本轮交易收益概率。

兴森2026显示2个B、0个最终方向S。15个有原始SELL候选的日期中，卖方支持最高40分，未达到至少两路独立支持与50分门槛。该股回放有2次实际卖出；全池22次实际卖出中，11次原始并集退出、9次真实账户止损、2次信号时固定MA退出，执行日均没有最终方向S。现有图表方向S与实际退出仍属不同协议，尚未把这些账户退出映射为主图最终S。统一卖点必须明确账户/影子持仓范围及退出时点，不能虚构一个无持仓账户的真实卖出，或把退出头的持仓概率当成独立入场评分。
