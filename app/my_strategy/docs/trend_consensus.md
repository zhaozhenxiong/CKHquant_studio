# 趋势共识策略

当前产品名称为“趋势共识策略”，页面不使用版本后缀。内部身份 `czsc_trend_consensus` 用于区分新目标与历史模型，历史报告保留原身份。当前默认账户是每只股票独立的研究 Broker 账户；账户起点、现金与模型绑定，显示区间只是图表裁剪。

## 每个 Agent 如何评分

均线 ML 使用20项均线与风险输入，独立预测未来10个核验交易日的上涨、下跌、中性概率，三者之和为1。起点是信号日后的下一核验开盘，终点是第10个核验交易日收盘。波动中性带由信号日前14日 ATR 与至少1%价格变动确定。趋势概率不是原交易获利概率，也不把 `1−上涨概率` 当作卖出概率。

买方基础分为 `0.4×上涨概率 + 0.2×结构买方强度 + 0.3×量价需求强度`。已存在的合格买入候选、实际空仓账户才计算高收益概率，额外贡献 `0.1×高收益概率`。卖方分为 `0.4×下跌概率 + 0.2×结构卖方强度 + 0.3×量价供给强度`，最高0.9；高收益入场概率不参与卖方或买卖差额。

结构和威科夫值是规则证据强度，不是概率。每个来源的买卖两侧共享同一权重预算；同源冲突、依赖家族合并、候选年龄和风控按冻结契约处理。缺数据或兼容模型显示不可用及原因，不补0，不把缺失权重分给其他 Agent。

连续支持与新机会分开：持续高概率不会每天产生B。候选必须是首次确认的原生机会或满足趋势确认的概率首次穿越；检查点切换不会自动制造新候选。高收益为空时区分无候选、持仓期间不适用、风险阻止、输入不合格、缺兼容模型和身份错误；已有分数再区分通过或未过质量门槛。

180股独立政策池的已选参数为：趋势候选穿越0.55、买方基础0.40、普通卖方0.35、买卖方向差额0.10。该选择仅使用2023年末单独政策段，179只股票在该段有行情；不使用四个已读开发季度。高收益0.10和买方总分0.50仍是预登记基线，不称为已经按开发收益优化。界面和默认请求读取实际模型报告中的配置，配置文件的初始值不会覆盖保存的选项。

## 最终 B/S 与成交

主图默认只显示选定账户的最终动作意图。点击 B/S 才展开各 Agent 分数、贡献、原始证据、参考价及账户状态；不点击不显示弹窗。没有 B/S 的 K 线也可点击查看当日评分，这类查看不会生成买卖标记或信号参考线。日、周、月聚合保留原动作日期，各自买卖分组，成交使用实际执行日期；周月线的评分查看可切换该周期内已核验的日线日期。独立方向诊断可另行开启，不能冒充账户动作。

普通S来自连续仲裁。真实持仓还可以因硬止损、60核验交易日上限、当前持仓入场计划冻结的已确认结构失效边界，以及入场信号时固定的独立 MA 持仓退出模型生成S。这些出口不需要高收益入场评分，也不要求两个来源投票。任意原始结构卖点不再绕过仲裁直接平仓。退出模型在持仓中不升级。

收盘动作由下一核验交易日开盘的 Broker 执行，遵守T+1、100股单位、费用、滑点、价格和成交量约束。已冻结保护订单的开盘跳空止损记录当天09:30及真实开盘参考价。拒单或部分成交保留最初意图，后续执行不回填为最初次日成交。B/S参考价和成交价分别显示。

本研究的 Broker 成交价格采用滑点后的连续模拟均价，可以包含小数分，不是交易所逐笔报价。2R 的 R 则沿用已冻结标签定义：按入场实际含费扣款，减去止损参考价经滑点、按0.01元 HALF_UP 取整并扣卖出费用后的假设净收入；它是冻结止损参考风险，不是已经发生的真实止损损失。该参考口径与连续均价口径不同，180股固定账本敏感性审计的参考风险相对差异最大12.476%；全部2800个成熟E1高收益标签未翻转，E0入场描述有1个翻转且不用于训练退出头。不能据此把后续统一定价当作无影响修改；改变成交或R定义都要建新协议、重新生成相关账本与标签，不覆盖现有模型。

分析和扫描沿用模型声明的2023-01-01账户起点；显式回测从所选回测开始日以每股独立初始资金建账，属于另一账户。打开已保存分析时保留实际模型运行、账户起点、每股资金及核验日历，自动模式只在该模型运行内部按日期选择检查点。请求日没有该股行情时，不沿用前一日评分；非交易日或超出原始行情截止日的请求会披露请求日期和实际核验判断日。

威科夫事件开关展示原始确认或待测试事件。历史表点击日期重算当时可见证据与参考价；右侧120日成交量加权价位分布跟随当前指向的K线截止日，仍是量价估算。

## 模型与时间

训练顺序为独立三分类趋势 → 无高收益过滤的 E0 实际账户 → 基于 E0 续持的独立 MA 持仓退出模型 → 信号时固定先验退出头的 E1 账户 → E1 下费用后完整交易区间 → 新高收益入场模型与仅作影子观察的 L2 退出/优势模型。高收益标签要求完整清仓后至少8%且至少2R；拒单、未清仓和未成熟的配对不会成为负样本。

训练、概率校准、政策选择与锁定开发评估按时间分段。趋势每类至少100条训练、30条校准和30条政策样本；不足明确不训练。首版线性高收益模型为预登记主控，树和 MLP 为受控消融；不称为已选出收益最优模型。历史重建严格使用判断日前可用的模拟检查点，同时披露今日实际训练完成时间。生产时间模式只允许已经实际完成的模型，不伪写历史部署。

20日方向敏感性另建独立标签、模型、时间拆分和运行身份，仅比较覆盖与校准，不替代10日主目标，也不接入当前账户退出或高收益标签。

当前原始行情截止2026-10-09，冻结模型特征源截止2026-10-08。60股固定开发池保留；扩展训练池由预先声明的历史覆盖与股票身份哈希选择，扩池仅由成熟样本不足触发，不按收益选择。四个已读季度和2026YTD仅是开发诊断。完整源码、配置和模型实际冻结后的至少三个480交易日独立窗口尚未成熟，收益认证状态仍为 pending。

## 自行调参

配置位于 `configs/czsc_trend_strategy.json`。当前模型使用自身保存的配置，直接改这个文件不会篡改已训练模型的契约。

0.1.3公开的 `configs/current_strategy.json` 不绑定开发机运行，`model_run_id` 默认为null，自动查询本地合格模型。没有模型时明确不可用，不回退到旧模型族或补概率。已有研究模型可以用自己的独立选择JSON并通过 `KHQUANT_CURRENT_STRATEGY_CONFIG` 指定；填写自己的运行ID后，运行内部仍按日期匹配合法先验检查点。开发机180股运行保留原选择，有两个合格历史高收益入场检查点；最近校准段无正例，未生成新的最新入场头，自动资格仍false。

显示层的时间区间、日周月切换和图层不要求重训。高收益质量门槛及最终买方总分门槛可在新研究请求的 `consensus_config` 调整，保留新请求配置和独立账户身份。权重、买方基础门槛、卖方门槛、方向差额、证据有效期、候选规则、风险、资金、趋势周期或续持出口改变，需要重新生成相关标签与模型；接口会拒绝不兼容模型混用。

例如研究分析请求中的 `"consensus_config": {"high_return_threshold": 0.10}` 只覆盖质量过滤门槛，其他参数继承所选模型的冻结政策；`buy_total_threshold` 同理。这个过滤门槛不同于标签目标中的最低费用后收益和最低R倍数。重训改变标签目标后，页面读取新模型保存的 `min_net_return`、`min_r_multiple`，不固定显示8%与2R。关闭 `require_high_return` 仅作为显式E1对照，页面会显示质量过滤已关闭，不能冒充默认完整策略。

源代码环境训练命令：

```sh
PYTHONPATH=app .venv/bin/python -m my_strategy.scripts.train_trend_consensus --source-native-run-id YOUR_COMPLETE_NATIVE_SOURCE_RUN --end YYYY-MM-DD --cpu-workers 6 --device cpu
```

新机器显式提供自己的完整原生来源运行和核验截止日，脚本中的历史默认ID不是可下载的模型。提供新的参数 JSON 时添加 `--config /绝对路径/参数.json`。每次生成独立运行目录，旧模型不覆盖。模型状态、校准、来源、实际账户账本及冻结协议保存在对应 `artifacts/runs/运行ID/`；当前入口选择仅代表功能交付，不替代独立收益认证。
