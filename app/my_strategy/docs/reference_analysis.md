# 行情参考分析与精简训练证据

默认分析与扫描用于行情参考：显示已知收盘时点的趋势方向、均线、结构与量价支持，以及完整来源B/S与最终共识B/S分层参考点。参考点可同时描述买方或卖方证据，不受模拟空仓/持仓或资金约束；因此不把它称为实际成交动作。

账户状态相关的退出、高收益入场资格仍在历史训练验收中计算。分析入口不给出虚构的持仓退出概率，不将候选模型当作合格当前选择。新入口同样遵守时点截断和来源校验。

新训练账户格式保留原始逻辑对象，通过共享对象引用去重，再以标准gzip保存，避免逐日重复复制全部历史成交与状态。说明文件、压缩资产、Parquet样本与成交证据分别绑定SHA；读取核验格式、路径、字节及语义一致性。格式更改不能改变标签、样本mask、费用、成熟规则、Broker成交或自动选模门槛。

旧权重与无用派生实体已退役删除，历史审计事实保留；不做原地格式迁移，不恢复旧模型资格。新训练使用完整的历史合格股票并集及原核验输入，冻结新的代码身份。

用户策略回测、资金账本与手动持仓编辑已直接删除。仓位参考使用独立风险计划、1%风险预算和95%单股上限；风险cap与积极配置目标分开，缺合法参考质量人口不伪造目标。可选持仓比例仅作敞口比较。详见 `bs_position_reference.md`。
