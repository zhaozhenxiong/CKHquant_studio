# 当前模型训练与默认参数

网页“模型训练”使用一个当前趋势共识模型包，依次重建原始来源、原生特征、趋势预测、固定均线持仓退出、预登记E1实际持仓配对、严格先验实际空仓尝试人口、高收益入场和独立持仓退出观察。旧模型及身份已退出当前运行路由；旧权重与无用派生实体直接退役删除，历史审计事实可查，不恢复旧模型资格。

1. 在“参数设置”修改页面列出的训练参数，保存个人默认。每次保存追加修订；并发编辑时须重新读取最新修订。
2. 点击预检。系统读取本地原始行情和独立核验交易日历，冻结本次参数、来源、历史合格股票并集、逐日资格、评估窗口和当前对照模型。没有有效预检计划不能提交训练。
3. 启动后台训练。页面显示阶段、来源和训练运行标识；取消终止子进程树，已完成的来源与日志保留用于核验。
4. 查看结果中的模型资格、正类流失诊断、真实费用后账本对比及自动选择原因。训练完成、模型头可用与收益资格分别判定。

完整训练包含全部历史合格股票，网页不再设置股票池数量上限或容量阶梯。流动性默认要求过去20个核验交易日的成交额中位数至少3000万元，页面金额以万元显示，保存和提交按人民币元换算。金额下限保留3000万元，可提高；回看范围可设20至120个核验交易日。每天仅使用当时已知输入判断资格，不能用今日股票名单替代历史逐日人口。

“每批处理股票数”默认360，可设1至10000，仅调整计算资源分批，不截断合格股票。预检分别展示历史合格并集和截止日合格数；任务和模型结果单独展示实际完成数，未报告时不把并集数量当成完成数量。旧含数量上限的默认配置保留为只读归档，迁移追加当前修订，原修订和任务不被改写。

360是股票准备分组上限，不是同时处理360股；CPU准备进程数控制CPU并行。神经训练行批默认2048行，决定线性/MLP每次训练批的样本行数，与股票分组不同。MPS可以执行支持的线性/MLP训练；支持的神经批推理须有实际设备报告。字典、CZSC、Broker/state、三分类方向和树模型继续使用CPU。阶段说明区分冻结请求设备、阶段实现规则与任务实际报告；未报告不推断为已用MPS，也不展示推算的GPU利用率或预计完成时间。

设备选项按训练能力接口标注可用性。指定不可用MPS时保留原选择并阻断预检，不静默换CPU。“本次选择MPS/CPU/CUDA”建议按钮只采用接口当前报告可用的明确设备，修改本次表单并要求重新预检；不提交auto、不保存个人默认，也不改变已经提交的任务。

政策网格仍逐一执行全部组合及真实Broker账户。同一只股票、同一折、同一趋势交叉阈值下，可以复用仅含因果事实和风险输入的准备结果；买入、卖出、共识差值门槛仍逐组重新仲裁并生成完整配置身份。此准备结果只存在当前worker，不跨股票或折保存，不缓存账户决定、标签或未来收益。政策进度在整股的全部组合写入后更新实际完成数。

线性/MLP使用明确选择的MPS设备时，已完成预处理的X、目标和样本权重可一次驻留设备；三组输入tensor的驻留预算为512MiB，超过预算按原样本批次搬运，仍使用MPS。此预算不包含模型、Adam状态、梯度、随机排列及Metal缓存，不是总GPU内存上限。每轮使用原CPU种子生成相同样本排列，保持梯度更新和浮点精度；损失按原批次顺序汇总，只减少设备等待。实际设备和搬运方式写入各头manifest。

完整且未导入模型或标签的原始/原生来源，可在预检请求中通过`source_native_run_id`明确选择复用；它不是保存的默认参数，训练提交不能另换来源。复用先冷读核验全部来源、日历、价格和单位、逐日人口、完整合格股票并集、资产SHA及原生生成代码，冻结证明，并在提交和实际领取任务前再次检查文件身份。来源输入配置、日历、人口或生成代码改变时拒绝复用。只复用已完成输入，所有模型、标签、政策账户和真实费用后比较仍重新生成。每个新计划冻结当前训练代码；旧预检或未完成模型不能取得新代码的资格。

截止日留空表示预检时冻结最新已核验交易日。明确填写非核验交易日时展示阻断原因及邻近核验日，需要修改日期或留空重新检查。开始按钮旁持续说明未预检、正在检查、预检阻断、参数已变或已经提交。检查失败不会显示为参数变化，提交成功也不会误报参数变化。

“训练与复核任务”默认折叠，摘要仍显示活动阶段、实际进度、失败和资格／诊断阻断数。展开和轮询保持用户的展开状态与滚动位置；双列时详情在右侧资格卡下边界内滚动，窄屏改用视口相对高度。详情可继续取消、查看诊断或重新核验已完成模型。

自动替换以完整模型包为单位。候选须通过内容、目标、时序、类别和成熟校验；完整冻结人口至少60股，各开发窗口至少50笔完整往返且总计至少200笔。费用后收益、单笔期望、回撤及双费用/滑点压力必须满足冻结方案对照门槛；证据不足保留待核验，差于对照拒绝切换。没有现任合格模型时用规则基线做初始化对照。运行中的参考扫描按冻结模型完成；切换前及事务内均检查活动扫描任务。手动账户功能已退役，内部训练持仓的退出头仍在入场信号时固定。

默认推理只读取已通过真实对比且已生效的选择事件。没有合格选择时显示观察与缺模型原因，不自动拾取刚训练的候选。切换按核验交易日生效；回退只能选择仍然有效的当前模型包，并追加选择事件。

T+1、费用、涨跌停、流动性、风险、高收益至少8%且2R、完整标签成熟、类别、严格先验和原子依赖清洗保持。正式独立收益认证与研究模型选择分别记录；至少三个完整独立窗口、每窗480个核验交易日的证据不足时仍为待核验。

缺失旧 `reports/research.json` 是退役历史产物缺档，不能据此要求当前体系重复训练。当前训练直接从本地原始行情生成新的来源和标签，不再读取该历史报告。

## 当前时点研究与重新核验

“当前时点研究”严格核验模型实际训练完成时间，输出为无账户参考结果。历史研究按日期匹配检查点，不能静默忽略当前时点或固定检查点请求。研究自动选择不会取得正式独立认证资格。

训练已完成而诊断或比较失败时，可“重新核验已完成模型”。系统校验原冻结计划、当前源码、真实来源、权重、目录和派生政策哈希后，仅追加诊断与比较运行，不重训、不改旧任务或权重。选模始终使用重新冻结的现任对照。

公开软件发行不包含训练权重，也不表示全量业务训练已经完成。任务、头资格、费用后比较、研究选择与正式独立认证分别读取实际报告；没有可用报告时不推断模型效果。

## 分析参考与训练证据

单股分析和市场扫描使用独立行情参考入口。三路方向支持与B/S参考点来自已知收盘信息，不依赖模拟现金、持仓或成交账本。图表参考价不表示成交价；需要实际持仓状态的高收益与退出模型在此入口明确不计算。缺少合格方向头时披露不可用，结构与量价事实仍可查看。策略回测、资金账本及人工持仓编辑入口与专用实现已删除；关注继续持久保存。可选当前仓位比例仅作参考比较，不形成实际库存或模型退出输入。

高收益训练仍使用真实历史模拟生成费用后8%且2R的标签，并保留成熟、严格先验、机会依赖及费用验收。参考页面不取得账户型目标的资格。新账户证据将重复成交前缀、状态与模型输出保存为共享对象引用，并用标准gzip压缩；三个账户JSON文件为明确格式的引用说明，共享资产必须进入manifest和SHA核验。读取恢复原始逻辑对象及语义hash，诊断按恢复后的成交重新计算目标。原产物不原地改写，新训练冻结新代码；旧权重不能绕过新生成码和选模校验。

## 2026-10-14 修复与重新冻结

三分类校准仅拟合正温度，类别截距格式不再取得当前资格。四个预登记线性配置只在清洗后的训练内部时间段比较，最终配置重新使用完整成熟训练行；校准与政策段不参与配置选择。各折报告原始/校准混淆矩阵、类别召回、log loss与最大类别改写计数。

L2入场保持逐折严格先验真实空仓尝试人口。退出与退出优势改读提前冻结的E1实际持仓配对，两个分支均实际清仓才成熟；持仓人口协议、manifest、数据SHA和冻结续持绑定模型目标及完整运行核验。不得用候选克隆或最终入场门控后的空表冒充该人口。实际退出头可训练不等于在最终门控账户上已经通过收益验收。

人口进度来自父进程的单个人口完成事件，E0、E1及各final fold分别以冻结股票总数计数；界面百分比表示当前阶段，可随阶段重置。旧逐股DATASET日志只作为详情，不再跨折累加。

新原生三卖镜像使用已确认笔与原生三买的对称价格语义，不修改冻结第三方算法。原native身份失效，完整训练按新冻结人口重新准备全部native输入；费用、8%且2R、质量0.1、MA退出0.55、优势0.002及原共识/收益比较门槛不变。只有真实完成全量训练、诊断和完整费用比较后才判定自动选择结果。

独立参考质量在E1真实持仓冻结之后、L2实际空仓逐折训练之前生成，与核心入场/退出人口分开。训练状态单独披露完成参考头、参考人口身份、参考费用资格和缺失原因。参考头不足或参考费用拒绝保持仓位pending，不改变原核心模型选择门槛。新阶段均按冻结股票池单独计数；head训练仍披露实际CPU，支持的PyTorch阶段遵守原设备配置。
