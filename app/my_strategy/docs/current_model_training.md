# 当前参考模型训练（0.1.7）

当前训练默认 `reference_position_v1`，公开模型族为 `current`。目标是参考买卖点与每股目标仓位/增减幅度；新链路不执行模拟成交，也不使用旧 Broker 标签、费用后 8%/2R 头或权重。

## 输入准备和预检

训练要求已有完整、无失败的因果 native 来源，连同 raw 行情、历史逐日流动性人口和已核验交易日历。来源必须包含全部历史合格股票并集，并通过文件 SHA、schema、来源链和数值生成代码核验。公开安装不附带这些业务资产；原始行情更新不等于完成 native 来源准备。缺有效来源时预检阻断，不能借旧模型报告或半成品继续训练。

在“模型训练”填写来源 ID（或让服务查找已有完成来源）、日期与参数，预检后提交计划。截止日及人口起始日必须与来源一致，新行情不会自动补入冻结快照。参数页可以保存个人默认；训练页本次修改需要重新预检，不修改旧任务。

```sh
khquant train-reference --source-native-run-id YOUR_VALID_NATIVE_RUN --device auto --preflight-only --json
khquant train-reference --source-native-run-id YOUR_VALID_NATIVE_RUN --device auto --json
```

`--config` 接受 [参数说明](../../PARAMETERS.md) 中的扁平 JSON 字段；默认训练 12 轮、8192 行批、4 个准备线程。完整人口不会按批次截断。旧 `train-trend` 入口已退役，不再继续旧成交研究训练。

## 数值训练和设备

新目标为下一核验日开盘到第 10 或 20 个核验交易日收盘的纯价格三分类方向；缺报价、异常价格或未成熟行保持不可用。58 项输入来自均线、已确认结构和量价事实，均按判断时点可见性处理。

训练内部时间划分选择线性或 32→16 MLP，随后用完整训练段重新拟合；预处理只在训练段学习。独立校准段仅拟合正温度，政策段检查预测基线，滚动留出段只报告结果。标签必须在所属时间段截止前成熟；留出指标不能反选配置。

Torch 训练、校准与批推理 auto 优先 CUDA、其次 MPS、最后 CPU。明确请求不可用设备会报错。文件读取、精确价格比较、因果结构和状态协调保留 CPU；实际设备写入报告，不用可用性推断利用率。

## 结果、恢复和验证

主要结果为 `reports/reference_training.json`，包含冻结来源、模型、窗口、指标和时间身份。运行先通过独立技术完整性核验才标记 completed。政策段 LogLoss 与 Brier 均须不劣于训练先验基线，才能允许对应窗口增加参考目标。技术完成、预测门槛、历史研究重建和实际冻结后的前瞻资格分别判定。

失败的新参考任务可以通过 `/api/training/jobs` 的 `resume_reference_run_id` 在同 run 接续。原数值代码、配置、来源、完整数据集及已完成权重须逐项核验；恢复适配器另行冻结，不能改旧数值目标或把半成品冒充完成。完整性复核只检查原资产并追加证据，不改权重。旧训练档案保持可读，但不能由新默认入口恢复执行。

每股目标变化相对上次参考目标计算。WAIT 保持；缺评分或基线未通过保留最后参考并标记 stale；可靠价格触发既有硬风险边界时可清零。来源 B/S 独立显示，手工仓位仅作额外比较。

本机已使用 MPS 完成来源截至 2026-10-12 的 3,194 股、四个滚动留出窗口与一个当前模型，并通过技术及真实分析/扫描验证。**当前模型未通过预测基线，不启用积极增仓目标。** 软件发布不附带模型权重，也不将方向指标写成交易收益。见 [架构](reference_position.md) 与 [完整训练结果](reference_position_validation_20261014.md)。
