# 图表买卖标记、历史参考价与多 Agent 证据

本文说明结构分析页的展示改进。本次没有新模型训练、策略晋升或正式版本发布；原正式 v0.1.2 的冻结模型、训练信号与账本继续保留，不称为正式 v0.1.3。

## 查看 B／S 与不同来源

- `B` 表示买入意图，`S` 表示卖出意图。同一股票、同一周期 K 线、同一方向汇总为一个标记；买卖方向分别保留。
- `B·3` 等数字表示参与该组的不同信号来源数，不是胜率。浮层同时保留原始事件数；同一 Agent 的多个不同事件仍可展开查看。
- 尚不可见、候选资格不通过的证据默认不参与主图标记，相关排除原因仍保留。模型参考门槛是否选择该候选另有状态，不能把出现 B 理解为已通过交易检查。
- 实际成交以不同形状及 `实B`／`实S` 标识，成交日、价格和费用来自 Broker 账本。

悬浮 K 线查看简要判断与对应筹码分布；点击固定日期和浮层，展开原始事件或使用“定位事件列表”。右侧事件的“定位主图”用于回到对应 K 线。按 `Esc`、关闭浮层，或点击“取消固定 · 回到最新分布”，解除固定选择。

## 四类 Agent 数值如何理解

| Agent | 显示内容 | 数值含义 |
|---|---|---|
| 均线 ML | 已保存的前向入场概率、规则状态、目标和模型身份 | 以浮层所列目标为准；三路高收益族的MA为完整费用后往返正收益，其他兼容入口保留其原目标 |
| CZSC 结构 | 当日已确认买／卖事件数及买卖点类型 | 规则触发计数，未输出连续概率，不转换成百分比 |
| 威科夫量价 | 需求／供给规则分 | 既有事件权重与事件龄衰减形成的 0–100 证据强度，不是获利概率 |
| 高收益区间 ML | 当日候选的 L2 入场概率与已保存辅助输出 | 冻结退出政策下满足完整区间高收益目标的研究概率；无候选日不补评分 |

这些数值的目标不同，不直接求平均。`0` 是真实零值；没有兼容模型、输入不足或未保存输出时显示“不可用”及原因，不填零。

退出模型需要截至观察日的兼容真实 Broker 持仓历史。普通股票分析中的 S 可展示退出规则证据；缺少该持仓契约时，MA／L2 退出概率保持不可用，不能以“1 − 入场概率”替代。

## 参考价、周月线与筹码

参考价按股票和信号可知日精确匹配当日收盘行情，保留价格日期、来源及价格基础。它是当日收盘参考，不是同日成交承诺；实际执行仍在下一核验交易日开盘经过 Broker 检查。缺失该日行情时明确不可用，不借用下一日、当前最新价或更早结构锚点的价格。

周／月图将周期内多个原始信号汇总到同一根已闭合 K 线，浮层列出各信号可知日与周期闭合时间。未闭合周期的已确认标记等待闭合，不把多日事件称为同一天同时发生。

筹码图使用截至所选日期的最近 120 根日线量价估算，保留图表显示区间之前的预热数据。悬浮周／月柱时按该柱对应的历史截止日展示；在固定浮层中点击一个原始信号日期，会切换到该日的日线筹码。形成中柱只使用当前已经观测的前缀。少于 120 根或窗口没有有效成交量时显示对应缺失状态。该估算不是股东真实持仓筹码。

## 按历史时点重新判断

展开“按历史时点重新判断 · 历史参考价与 agent 评分”，可查看选定日参考价、四类证据、已有风险区间及历史记录。历史表每页 20 行，支持上一页／下一页。

点击历史日期、移动回放滑杆，或使用上一根／下一根，会发送带 `as_of` 的真实分析请求。加载期间显示加载状态；成功后使用该次响应更新判断，失败时不把旧卡片当作新日期结果。历史记录只显示当前信息截止日以内的数据；“回到最新”重新请求最新分析。

展示数据契约为 `chart_evidence_v1`：逐日记录包含股票、日期、OHLC、收盘参考价、下一核验交易日、已有风险计划与 `ma`／`structure`／`wyckoff`／`high_return` 证据。每类证据保留类型、可用状态、目标、模型身份和缺失原因。模型可用时间不晚于该日，历史记录不复制最新概率，也不使用未来行情补值。

本改动只追加展示适配及历史筹码快照，不改原始 `signal_points`、来源哈希、模型参数、交易信号生成、Broker 账户或既有收益报告。可读页面与软件发布身份不等于模型已通过生产资格或收益改善验证。
