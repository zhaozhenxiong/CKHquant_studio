# 图表 B/S、历史参考价与 Agent 证据

0.1.6 主图同时展示来源参考点与最终共识参考点。结构、量价、合格均线 ML 按各自已确认可见日期标注；来源 S 即使未达到最终卖方门槛仍可查看。最终 B/S 按原支持、分差、独立来源和质量条件计算，不因显示需求补点。普通分析不执行资金账户，不把参考点称为实际成交。

点击 K 线或标记固定当日证据，弹窗显示来源、最终是否通过、Agent 分值与贡献、目标、模型/数据身份、风险和仓位资格。悬浮切换当日指标及量价估算，点击关闭或 Esc 解除固定。右侧事件可“定位主图”，历史重新判断发送真实 `as_of` 请求，加载/失败状态不能被旧卡片替代。

## 分值与仓位

| 内容 | 含义 |
| --- | --- |
| 均线 ML | 合格严格先验趋势头的上涨/下跌/中性概率及目标身份；缺模型明确未评分 |
| 结构 | 已确认结构的买卖规则支持，保留可见时间与原始锚点 |
| 威科夫量价 | 连续需求/供给、事件与最终支持，0—100 规则强度不是获利概率 |
| 独立参考质量 | 独立真实人口、头与费用资格均合格时的参考概率；账户型入场/退出概率不混用 |
| 风险仓位上限 | 1%风险预算及原止损几何计算的允许上限，不能替代积极配置目标 |
| 积极目标仓位 | 独立参考质量与原共识/来源/风险/价格/时间门槛全部通过才生成；否则 pending |

真实零值与缺失不同，不能补零。来源 S 是卖方证据，最终 S 表示减少敞口；WAIT 不猜测用户当前库存。可选用户仓位比例只用于与参考目标比较，不形成账户或模型输入。详见 [B/S 与仓位参考](bs_position_reference.md)。

## 参考价、周月线与量价估算

参考价匹配信号可知日的真实收盘价，保留日期和价格基础；缺价明确不可用，不能借未来或最新价格补值。研究成交另由内部 Broker 在下一核验且可执行开盘核验，参考价不是成交承诺。

日/周/月图保留原始信号可知日和周期闭合时间。高周期汇总列出各原始事件，形成中柱只读已观测前缀；尚未闭合的周期不能冒充完整确认。结构锚点不替代实际可知日。

70%区间是截至所指日期最近120根日线的成交量加权价格估算，不是真实持仓筹码。悬浮周/月柱使用对应历史截止日，固定弹窗可切回具体原始信号日；数据少于120根或缺有效成交量时说明原因。均线和布林带使用所选周期与当时已知数据。

历史模型和参考资格按当日时点核验，不复制最新概率，不使用未来证据补评分。软件发行、图表 B/S 或风险上限均不代表取得模型独立收益资格。
