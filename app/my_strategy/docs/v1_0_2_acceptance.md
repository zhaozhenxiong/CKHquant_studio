# v1.0.2 功能范围与发行验收

本版从 v1.0.1 的发行基线合入两轮已验收的界面和只读展示功能。源码工作区、部署验收和历史版本安装记录是不同证据；它们不替代本版最终 wheel 的跨平台验证。

## 合入功能

| 范围 | 验收要求 |
|---|---|
| 关注与模拟账户 | 关注股票、模拟账户二级页签；回测、保存与每日续算、费用后账户对照唯一挂载；旧结果链接、导出与用途标识保留 |
| 参数与任务 | 预测、回测、学习草稿独立；带入只填草稿，10 只回测上限明确；切页进度与取消针对当前任务，刷新不提交或恢复取消 |
| 历史预测图 | 读取原外层预测引用；历史截止日、内容 SHA、价格口径核验；真实 K 线与原未来路径同轴；30/60/完整显示不改模型参数 |
| 方法图与点 | 单股直接显示同次预测；原始证据折叠；只画截止日有效 BUY/SELL，来源历史图层独立；低质量可读图保留说明 |
| 全人口筛选 | 分页、查询和关注过滤不改变完整扫描分母；有效 BUY/SELL/WAIT 与不可用、失败、待处理分别计数 |
| 板块方法统计 | 明确选择匹配方法、日期和原参数的保存扫描；成员投影与报告哈希绑定；预测、评分和完整方法分母独立，未入扫描单列 |
| 身份与竞态 | 原模型含空值、开始日期、seed 0 正确恢复；草稿变化解除旧结果绑定；离开页面后旧响应不能覆盖草稿或重新打开详情 |
| 保留修复 | Windows 源码身份、跨卷存储、原生安装及任务生命周期/历史投影修复继续生效；已有账户、模型和来源保持身份 |

这些变化只读原结果或填写用户草稿。GET、切页、缩放与主题切换不启动预测、扫描或训练；模型权重、数值生成规则、参数默认和账户账本不随界面迁移改变。图中截止日不是已核验的预测生成时刻，方法点不是首次触发、成交或目标仓位。成员横截面不是板块收益预测，采样比例不是校准概率。

## 本版发行门禁

本说明编写时，合并候选的完整回归及最终 Windows x64 CPU、Linux x64 CPU、macOS ARM64 CPU/MPS 安装验证尚待执行。通过项必须由本版精确提交和最终物理 wheel 的回执支持，不能沿用 v1.0.1 的通过状态。CUDA、Intel Mac 等未实测范围继续明确未验证。

安装探针必须从 site-packages 导入，使用隔离合成业务目录，验证新页面/只读端点及已有真实 TaskManager + TaskMaintenance 生命周期；缺少必要字段或反例通过时拒绝验收。实际浏览器检查包括宽窄屏、明暗、键盘、任务/账户回归和旧响应竞态。最终状态见根目录 `RELEASE_VALIDATION.md` 与随资产的 `release-validation.json`。

公开源码、wheel 和 ZIP 不包含行情、权重、个人账户、私有审计、宿主路径或用户提示词。保留第三方来源和许可证，原生 CZSC 版本为 1.0.1。历史来源与账户只读能力不意味着可以绕过版本门槛续算；软件发布不授予市场有效性或独立前瞻资格。
