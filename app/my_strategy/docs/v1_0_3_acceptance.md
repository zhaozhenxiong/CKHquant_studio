# v1.0.3 验收范围与发行门槛

本版沿 v1.0.2 的真实 Git 历史合并，保留已发布的 Windows 时间戳、存储、原生资源和安装验证修复。发行包不包含行情、模型权重、个人账户、账本或私有审计。

## 本版改动

- 第二版市场工作区、已保存候选详情及条件价来源说明。
- 板块成员有界并行刷新、原生结构补齐、只读紧凑索引及首次加载优化。
- 资金区间 90 / 50 / 20，默认 20；长区间首次按需读取，后续缓存复用。
- 分析页面精简及预测依据可视化，设备与分析内容并列。
- 已有回测 B/S 仅读原始 Broker / Ledger 的 BUY、ADD、SELL、REDUCE 成交；不冒充当前日模型资格。
- 账户 CPU 因果输入有界准备和已完成日检查点节流；模型采样、时点资格和 Broker 逐日顺序保留。
- Kronos meta-device完整权重赋值、真实张量设备与分段计时；组合扫描和完整账户有界spawn原生准备。

## 本机实测与等价范围

| 测量范围 | 优化前 | 优化后 | 结果 |
|---|---:|---:|---|
| Kronos 卸载模型的新进程首预测，中位数（各3次交错） | 2.6777秒 | 2.0956秒 | 耗时减少21.739% |
| 上述范围中的模型加载 | 1.2424秒 | 0.6808秒 | 耗时减少45.206% |
| 16股完整冷原生准备，2进程 / 8进程 | 58.4313秒 | 19.7735秒 | 2.955倍 |
| 两股188交易日、206次32采样、4策略的完整真实模型账户 | 320.4769秒 | 267.3250秒 | 耗时减少16.585% |

Kronos首预测从Torch导入及原始frame读取之后开始计时，OS文件页及MPS kernel缓存共享/预热；不代表整台机器首次启动或整个API延迟。初次未预热的5.139秒调用含kernel设置，单独保留，不能用于归因。暖推理未获得实质提速。64次真实CPU/MPS预测的完整路径及数值/质量输出逐位相同，采样参数与RNG顺序不变。

16股结果的原始行、特征、事件及来源身份完全一致。2 / 8进程的进程树峰值RSS约0.72 / 2.13 GB，增加并发需要更多内存；该倍率仅覆盖CPU原生准备。

完整账户是一次本机Apple MPS配对，包含新模型推理、因果调度、逐日Broker及检查点。206次fresh调用都核验了实际张量设备。4策略76字段与4完整比较对象通过811条已证明的因果前缀谱系SHA映射等价；原JSON不相同。成交、订单、费用、净值、风险及指标等经济字段直接完全一致，预测数值与质量相同。旧来源身份保留，新历史前缀依赖精确重建，不能把所有ID字段删除后比较。相同口径总准备耗时14.4426 → 8.3165秒；新纯source阶段7.4732秒不与旧总准备混比。单次本机结果不保证所有股票池或平台同倍率。

## 验收合同

最终源码必须重新冻结、同步及逐项 SHA 核验。候选源码的完整测试、边界和真实入口验证通过后才能推送。三平台 CI 构建新 CZSC 资源并组装统一应用 wheel；同一最终 wheel 必须通过 Linux CPU、Windows CPU、Apple Silicon CPU 与 MPS 实装验证。源码 ZIP、wheel、原生索引和报告均绑定同一提交与 SHA。

本文件准备时所有 v1.0.3 最终平台资产均待验证。以随发行附带的 release-validation.json 为准；旧版证据不替代本版验证。CUDA 和 Intel Mac 不在本版验证矩阵。软件安装与模型资格分别判断。
