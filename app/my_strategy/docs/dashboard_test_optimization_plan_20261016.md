# 工作台全功能测试与布局、性能优化计划

日期：2026-10-16。目标：http://127.0.0.1:8124/ 。先测量与测试，再修复布局和已证实的性能瓶颈，最后回归；不以降低数据核验、模型质量或计算精度换速度。

## 1. 范围与完成标准

覆盖结构分析、全市场候选/方法回测/板块、我的关注/模拟账户、预测与模型、高级训练、参数设置、数据与任务，共7个视图、72个API路由声明。各功能记录正常、空、非法输入、缺数据/模型、失败、部分完成、取消、并发晚响应与重启恢复的适用测试。

测试分层：线上有界交互和只读接口检查；临时业务目录中的写入、删除、任务与训练契约测试；完整Python回归、Node组件测试；桌面/平板/手机及明暗主题的真实浏览器核验。删除、清理、模型晋升和保存账户的写入在隔离环境测试。长计算使用隔离合成输入验证生命周期与契约，完整真实市场重新计算单列未执行项，不将单元测试当作全市场计算通过。

所有发现记录优先级、复现步骤、证据、修复、验证结果。未实现能力不算测试通过：多方法一致性、连续看涨、全市场历史资格、每日买入区间单列后续能力。

## 2. 执行顺序

1. 工作区、最新约定、活动任务、真实数据截止日与保护边界核验；创建AI审计会话，保存修改前源码快照。
2. 清点全部页面/API/控件及已有测试，形成逐功能矩阵；对真实页面截图并检查错误、导航、输入、筛选与图表。
3. 测量页面常用GET的首轮/重复耗时、响应大小和重复请求。将冷读、缓存热读、并发争用分别记录，报告样本数；不把首次耗时差异直接归因于优化。
4. 执行完整自动回归。覆盖关注与账户持久化、冻结身份、预测历史核验、方法方向、部分覆盖、取消恢复、精确清理和受保护资产。
5. 修复数据页的信息层次、任务筛选和运行列表密度；保留既有全市场候选布局和业务入口。处理有证据的重复请求、无效预加载；后端慢接口按性能证据另行修复。
6. 重跑受影响测试和完整回归；在1488、908、390px检查横向溢出、按钮换行、长文本、主题、展开/折叠和分页。核验最新数据与模型资格未被展示变化改写。
7. 保存报告、截图、前后基准和未覆盖项；完成AI审计。以实际测量结果交付，不承诺未经比较的“最快”。

## 4. 性能和布局验收

- 正常热读列表目标低于300ms；超过1秒的接口记录具体阶段与原因。这是优化目标，不是现有性能保证。
- 同一时刻同一列表的重复刷新合并；不长期缓存可变任务状态，不丢手动刷新和失败后的重试。
- 非数据页面不预加载运行记录；运行记录以每页6条展示已加载最近30条，明确范围，不冒称全历史分页。
- 活动任务在设备说明之前；计算设备说明可展开，任务筛选与操作对齐；移动端按钮换行且无整页横向滚动。
- 缓存必须有身份/来源/修改失效和容量边界；性能修改不得改变冻结人口、价格精度、预测参数、模型、账户或资格。
