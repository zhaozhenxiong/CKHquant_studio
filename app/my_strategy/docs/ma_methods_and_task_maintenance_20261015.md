# 均线组合方法与任务维护

结构分析、全市场扫描和独立模拟研究支持均线特征版本；旧混合模型保留原名称、输入和资格，不通过改名冒充均线模型。

## 方法与结果

| 页面名称 | API / CLI 方法值 | 计算内容 |
|---|---|---|
| 结构与量价 | `structure` | 已确认结构及量价来源 |
| 结构与量价 + Kronos | `structure_kronos` | 相同来源与本地冻结 Kronos |
| 结构与量价 + Kronos + 均线模型 MLP | `structure_kronos_ma_mlp` | Kronos 加 `ma_trend_v1` MLP |
| 结构与量价 + Kronos + 同输入 L2 | `structure_kronos_ma_l2` | 同一 MLP 产物内的配对 L2 |
| 历史参考模型（对照） | `legacy_reference` | 明确保留的旧参考链路 |

分析与扫描共用方法服务，冻结模型、日期、股票池、原始行情物理 SHA、核验日历以及原生、预测生成身份。`method_context` 用于保存复原、钻取和续批；自动选择也记录实际候选 ID。表单与原结果仍匹配时，模拟研究跳转携带该实际模型；修改表单后不能带入不对应的旧模型。

`method_evaluation` 保存独立来源、Kronos 采样摘要、MLP/L2 评分、方向和缺失原因。采样分位数与上涨比例未经校准；评分模型的资格由实际字段显示。模型与预测方向不一致时保留 WAIT。缺模型、缺行情、预测不可用、失败和预算延后分别标识，不填零、不沿用前日结果。无账户分析不执行订单或生成实际仓位。

普通分析使用有界预览缓存，显式保存才创建永久运行。改变评分模型不改变原生结构输入身份。组合方法只计算截止日，不伪造过去 30 日预测历史。

## 均线 MLP 与配对 L2

`ma_trend_v1` 有 20 个固定顺序特征：MA5/10/20/60 偏离与斜率、排列、间距、收益、ATR、波动和回撤。没有额外的缺失掩码列。训练直接读取核验原始价格；预处理仅拟合训练段，训练、校准、政策和测试按时间分离，标签成熟和因果质量门槛保留。

`POST /api/light/score/train` 的 `feature_profile` 可选 `ma_trend_v1` 或 `mixed_v1`。均线界面固定 MLP、A 版，同步训练内嵌的同输入 L2；旧 `score_model_type=l2` 简单模型不等于配对基线。新组合方法只解析兼容的均线候选。CLI 训练均线模型须显式指定 `--feature-profile ma_trend_v1`，缺省保留旧兼容行为。

MLP 和 L2 比较必须使用同一候选、相同输入、预处理、日期与人口。历史评分或测试指标不授予独立前瞻资格，不自动改变现有账户的固定模型。公开测试 fixture 为合成数据，不包含可用训练权重或真实候选 ID。

## 有界扫描与续批

空股票池使用完整支持人口并排除北交所，默认每批最多 200 次预测、300 秒。每份报告保留失败、不可用和延后项；部分覆盖不能显示为全市场完成。预算停止新增计算，退出、完整性核验和保存仍须完成。CPU 来源准备上限为 4 个 worker，预测由协调进程负责；完成补位不改变冻结人口的预算消费顺序。

`POST /api/tasks` 使用 `kind=scan` 和 `spec.analysis_method`。共同参数为 `score_model_id`、`lookback`、`horizon`、`samples`、`seed`、`device`、`budget_seconds`、`max_predictions`。`resume_scan_id` 引用保存批次，续批生成新运行，旧结果不改写。股票池、日期、模型、行情、日历或生成身份不同会拒绝续算。任务取消保留已完成项，不自动恢复。

CLI `analyze` 和 `scan` 支持 `--analysis-method`；新请求缺省保留历史参考兼容行为。组合方法应显式选择。`scan --resume-scan-id <saved-run-id>` 可继承原方法及未显式传入的冻结参数；显式差异会拒绝。组合方法拒绝旧共识配置、旧模型检查点、显式旧日历和账户仓位参数，避免静默忽略。

比较扫描时分别统计完整可用、partial、failed、unavailable 和 deferred；占位 WAIT 不计为有效观望。核验共同原始人口、日历、代码、预测参数和同股预测缓存键，再比较方向及评分。来源事件数量与模型方向独立保留。

## 页面与任务维护

分析方法和模拟研究按钮在同一操作行，跳转携带股票、日期、方法、模型及预测参数，不自动启动回测。扫描开始/结束日期对齐，默认最新日期行为保留；打开个股结果会正确切换到个股面板。

数据与任务页统一旧任务和轻量任务，支持状态、来源和类型筛选、分页、单项与全部折叠、单项与批量删除。刷新保留展开状态。运行中任务不能删除；删除记录保留结果。物理清理是独立的预览与执行操作。

| 接口 | 用途 |
|---|---|
| `GET /api/task-history` | 分页历史和数量 |
| `GET /api/task-history/overview` | 一致快照中的活动任务与历史页 |
| `POST /api/task-history/delete` | 精确 `{backend, job_id}` 列表 |
| `POST /api/task-history/cleanup/preview` | 精确候选、保护项、计划 ID 与 SHA |
| `POST /api/task-history/cleanup/execute` | 重验同一计划并执行 |
| `POST /api/task-history/cleanup/recover` | 恢复执行中断后的隔离产物 |

预览显示引用与可回收空间核验状态，防止重复提交。回收仅覆盖可证明无引用的白名单产物；原始行情、必要模型、账户、关注、原生来源、核验日历、板块链、共享对象、固定引用、活跃租约与审计保持保护。执行重验边界、SHA 和状态，拒绝符号链接、共享硬链接、未知文件及预览后变化。

旧账户的历史结果可查看；只有实际核验报告算法身份变化时，才显示续算需新建账户分支。不能无依据把所有旧账户标成失效，也不能改写旧身份绕过核验。
