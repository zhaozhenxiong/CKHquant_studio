# 高收益正样本与退出人口诊断

当前 `model-diagnostics` 对完整的 `trend_consensus` 运行追加只读诊断，核验冻结候选、真实 Broker 标签、费用后联合目标、输入、成熟和原机会依赖过滤。它不重训、不改权重、原任务、标签、门槛或选择资格；旧并行诊断命令与模型身份已退役。

```bash
khquant model-diagnostics --model-run-id YOUR_COMPLETED_CURRENT_MODEL_RUN --cpu-workers 2 --json
```

`--cpu-workers` 可设1至4，默认2。进度写入标准错误，标准输出为 JSON；核验失败返回非零。输出在新 RunContext 保存报告与逐折 parquet，输入/输出资产各有 SHA，并绑定冻结来源报告、协议、人口与日历。先比对哈希，再按股票、信号日、原机会和 attempt 身份定位样本。

## 看懂人口和正类流失

各折训练、校准与政策段分别核算，不能将重叠人口相加当成独立样本。入场使用严格先验实际空仓评分前尝试人口；退出与退出优势另用预登记 E1 实际持仓配对，不能用最终入场门控后的空表代替。

1. 核对完整冻结股票池和每折人口：原始机会、逐日尝试、依赖块、持仓不适用、风险阻断、机会失效与缺模型分别记录。
2. 核对标签可用性：入场拒单、缺下一核验行情、未清仓、输入不足和段截止前未成熟分别记录；不可用不能变成负类。
3. 核对联合目标：费用后盈利、至少8%、至少2R与同时通过两者分别计数。完整清仓及段内成熟均通过才进入标签；盈利不等于高收益正类。
4. 核对过滤：列顺序/schema、成熟、原机会跨段原子依赖与段内计权逐层披露，互斥首次失败原因不与独立条件计数混加。
5. 核对资格：训练至少100行、校准至少30行且两段均有两类；数量够但正类为0仍不可用。原质量门槛、费用和高收益目标不为凑样本降低。

候选克隆的实际成交、费用、现金流、止损分母、R、清仓日期与 pooled 标签重新计算后应一致。E1 实际持仓 manifest、原始账户及退出 pooled 数据单独做资产与类别诊断；最终门控策略没有交易，不表示该退出头已通过收益验收。

## 当前修复与边界

三分类趋势校准仅拟合正温度，保留原始/校准混淆矩阵、各类召回及最大类别改写计数；不能用改类别截距、合并时间折或降低类别门槛掩盖下跌识别不足。

L2 退出修复后按 E1 真实持仓冻结人口重建，两个退出/续持分支均实际清仓才成熟。入场继续用严格先验尝试与强制一次 Broker 标签克隆。独立参考质量另有真实探针人口、头和费用资格，其诊断不替代账户型入场/退出目标。

诊断成功仅表示现有资产可核验，不取得自动选择或独立收益认证。旧权重与无用派生实体直接退役删除，历史审计事实保留；新训练与诊断使用新冻结身份，不能将旧运行名套到新人口。缺近期关键头、正类或完整费用证据保持明确阻断，正式独立前瞻认证继续 pending。
