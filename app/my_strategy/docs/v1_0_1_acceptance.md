# v1.0.1 功能验收范围与研究边界

本版候选合并已验收的组合方法、任务维护、北交所范围和运行优化实现，并保留既有原生安装及平台修复。本说明记录功能合同与验收项目，不把运行目录或旧版本的测试数量当作最终发行资产的通过证明。最终同字节安装结果见根目录 `RELEASE_VALIDATION.md` 及发行资产中的 `release-validation.json`。

## 已验收的功能范围

| 范围 | 行为与核验内容 |
|---|---|
| 组合分析 / 扫描 | 两页方法一致；均线 MLP 与同输入 L2 配对；保存和钻取保留日期、参数及实际模型；显示真实资格与独立缺失原因 |
| 预算续批 | 完整人口及失败、不可用、延后项保留；续批冻结身份和已有行核验；取消不自动恢复；预算前置、排空与保存耗时分别记录 |
| 页面交互 | 方法与操作行、日期对齐；从板块路由打开个股结果；数值预测摘要、候选资格、待处理状态；窄屏布局及任务展开状态 |
| 任务维护 | 统一分页与筛选；终态记录删除不删结果；精确计划预览/执行/恢复；引用、活跃写者、路径、哈希及幂等保护 |
| 股票 / 板块范围 | 新入口排除北交所并识别别名；不误排显式沪深 B 股；新板块只使用沪深 A 股投影；无当前结果不回退；历史来源和统计保持原样 |
| 缓存 / 来源 / 执行 | 对象级引用计数、共享 SHA、多 owner 与租约；批量原子发布；有界完成补位；原生追加、重启、历史修订与完整精度；单实例预测 |
| 持久任务 / 状态 / 结果 | 接单先落库；owner/取消/中断与输出意图恢复；状态摘要失效；旧报告不可变；分页拼接与完整结果等价 |
| 标签 / 资格 | 新训练未来价格、来源、日历和成熟门槛；MLP/L2 同输入对照；旧权重和资格不改写；缺证据不晋升 |
| 恢复 / 审计 | 保护对象恢复到独立目录；缺保护对象、损坏与越界拒绝；无 Git 内容差异审计；部署前后身份和必要资产保护 |

功能验收包含隔离回归、真实输入的数值等价与页面检查。对照区分冷来源、热复用、追加和预测负载；不把元数据微基准外推为全市场固定倍率。原生近似方差候选未准入，lossless delta 没有成为默认缓存格式；新增索引、状态和备份会占用空间，不能宣称全库净缩减。

## 本版公开候选验证

公开方法 fixture 使用确定性的合成模型 ID、日期与数值，保留摘要格式、资格分支、身份传递和表单变化回归；不携带真实训练资产。公开安装检查须使用隔离目录，从最终 wheel 的 site-packages 导入，核验版本、源码提交、资源与物理 SHA。

截至本文编写，本版最终 Windows x64 CPU、Linux x64 CPU、macOS ARM64 CPU/MPS 安装验证待执行。CUDA、Intel Mac 等未实际执行的平台保持未验证。后续安装回执必须绑定本版最终资产，不能沿用历史版本或开发机记录。本文不代替发布门禁。

## 研究和维护边界

- Kronos 采样频率与分位数不是校准概率或可执行收益；来源 B/S、模型方向、目标仓位和 Broker 成交分别展示。
- 历史候选可用于明确标识的研究；训练、回测、软件验收和发布不授予独立前瞻资格。未知预训练范围、未复权价格及历史规则资料不足仍须披露。
- 旧模型、账户、报告和来源保留身份。算法版本变化或必要来源缺失时，历史结果可查不等于可以续算，不能降低门槛自动升级。
- 北交所历史行退役与保护性恢复是独立维护；安装、升级和日更不会隐式清库。混合来源与历史审计中的旧事实保留，不能按字符串删除。
- 取消和时间预算是协作式边界，结束计算后仍需安全排空与保存；活跃任务、共享引用及未知资产不进入自动回收。
