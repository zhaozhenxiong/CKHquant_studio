# v1.0.1 计算与增量来源实现

本文件描述发行候选中的最终行为，不保留开发过程中的暂存目录、私人运行或待执行计划。源码测试与本版最终安装验证分别记录，见根目录 `RELEASE_VALIDATION.md`。

## 输入、标签与调度

新训练采用 `verified_direction_label_v2`：信号日后的标签交易日必须在核验日历连续存在，来源和 `has_trade_price` 合格，OHLC 有限、为正且几何有效，成交量/额一致，不能是停牌日；显式 `available_at` 不得晚于该日收盘。入口、区间、终点、未成熟及日历缺口分别记录。合格样本的三分类公式不变，L2 和 MLP 使用相同构造器。

CPU 准备任务完成后补位，缓冲最多为 worker 数的两倍，应用上限保持 4。预测、逻辑额度与最终人口按冻结顺序消费；后完成股票不能占用前面股票的额度。Kronos 在协调进程单实例运行，不为每种方法建立重复模型。相同冻结输入可共享结构和预测缓存。

来源准备和预测共享已核验原始快照，精确字段参与 SHA。`ma_raw_source_v2` 将价格可用性纳入身份，即使价格和标签未变，可用时间变化也会使缓存失效。

## 分块与状态续接

来源读取以批量租约保护完整 manifest 依赖，解压与内容核验不占 SQLite 写事务。新分块原子发布；manifest 在同一事务延长依赖 TTL。退出路径释放租约。

等价 append 直接引用已闭合的 256 行分块，只编码未闭合尾块与新行。历史行、事件、因果字段和价格 float64 保留；不能以 mtime 替代实际 SHA。轻量来源使用紧凑 evidence sink，保留末日解释、完整事件、标量及原生状态；其他调用者默认仍获得完整输出。

`native_evidence_state_v2` 保存显式 Wyckoff 状态机，绑定 schema、设置、原始及资格前缀与 SHA。旧 v1 状态缺少新增状态时完整回放，不能伪装增量完成。`exact_trailing_mean_state_v1` 保存 float64 补偿、计数及必要窗口；只有冷启动逐值对照 pandas 精确一致才准入，并绑定 pandas 版本及历史前缀。

方差与部分量价向量仍使用完整前缀的 pandas 内核。未精确等价的短尾 rolling / 方差候选不启用，不放宽容差。增量状态减少部分遍历和编码，但不消除全部历史读取、前缀核验或向量计算。

## 身份与预算

数值身份闭包包含实际模块、原生函数、引擎来源、配置、schema、价格读取/日期/规范化、来源白名单、序列化、稳定 SHA、日历父链、资源定位及 NumPy/pandas 版本。方法身份另含评分、预测、特征顺序和预测资产核验。纯状态展示或图表变化不应使原生数值身份失效。新标签合同用于新训练，不改旧权重、资格或旧报告身份。

扫描总预算从入口起算，覆盖模型、资产、日历、人口、生成码和物理 DB/WAL SHA 核验。完整 SHA 分块读，定期检查取消/到期并核验前后文件状态；不缓存不完整摘要。身份尚未完成时超时明确失败，不创建伪完整或可恢复扫描报告。身份完成后预算到期保留 partial，主动取消保留 cancelled。

训练和回测预算从来源准备前计起，训练只获得剩余额度。`TimeoutError` 与 `InterruptedError` 分别传播，不发布半成品模型。预算属于协作式边界，不强杀正在执行的本地数值调用；退出、最终核验和保存的超出量如实报告。

`compute_info.timing` 区分前置、来源等待、预测/评分、检查点、排空和核验的协调进程 wall time。来源 worker 累计时间与这些阶段重叠，不能相加当墙钟时间。预测计时取本次调用而非缓存中的旧资源耗时。最终保存、总耗时和超出量写独立执行凭据；遥测写入失败不能改写已提交业务结果。凭据原子替换未额外 fsync，缺凭据不能证明报告未发布。

## 验证范围

回归覆盖连续追加、JSON 重启、周/月边界、历史修订、精确均值、身份依赖变更、训练及扫描预算、取消、进程/通信故障和保存完整性。性能必须分别报告冷来源、热复用、追加、预测主导与完整任务；合成调度收益不等于真实模型吞吐，源码验收不代替本版最终安装验证。
