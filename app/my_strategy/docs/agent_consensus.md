# 图表多 Agent 买卖点

主图的 B（买点）与 S（卖点）来自独立的市场方向仲裁。三路原始候选仍保留，只有通过仲裁且未被重复抑制的点显示在图上。

## 查看方式

鼠标移动只更新十字线、均线/布林带读数和所选历史日期的120日量价分布。点击 B/S 或带有最终点的 K 线才打开判断窗口；点击空白 K 线、关闭按钮或按 Esc 关闭。移动鼠标不会重新打开窗口。

窗口先显示当日最终结论和仲裁原因，再列各 Agent 的意见及当日保存的评分；原始候选放在可展开明细中。没有最终点的日期可在“按历史时点重新判断”的历史表查看 WAIT 及原因。

日线最终点是唯一来源。周线、月线按原始日期归入对应周期，同一周期最多一个 B 和一个 S；同周期存在真实的不同日期方向变化时保留两种标记。点开后可以查看该周期全部最终事件及各自日期。周期合并不重新训练或重新投票。

## 判断链路

1. **均线 ML**：对当日已确认的均线候选使用可见且兼容的入场模型概率；明确采用因果规则回退的日期保留规则身份。趋势失效可以形成方向 S，真实持仓退出模型需要兼容的 Broker 持仓资料。
2. **CZSC 结构**：使用当日可见的已确认结构买卖候选。规则触发次数不转换成获利概率；依赖均线的结构定义与均线归为同一证据家族，防止重复计票。
3. **威科夫量价**：使用当日已确认候选和经过输入核验的需求/供给强度。规则强度与模型概率分别显示。
4. **高收益区间 ML**：进一步过滤已有买入候选，并核验已有入场风险计划。v2 通过质量门槛后固定增加买入质量分 0.1，不增加独立证据数量，不支持 SELL；没有兼容的当日评分时不能凭最新评分补过去日期。
5. **仲裁 Agent**：按去相关证据家族计算买卖支持，执行门槛、冲突、风险及重复过滤，输出 BUY/SELL/WAIT、理由和来源事件身份。

默认 v2 使用均线 0.4、结构 0.2、威科夫量价 0.3、高收益质量分 0.1。前三路通过各自门槛后给对应方向贡献固定权重；模型概率和量价强度仍单独展示，不相乘、不混合成获利概率。缺模型或不可见证据属于弃权，剩余权重不重新分配。

BUY 需要至少两组独立 L1 证据、买方基础分至少 0.5、买方基础分领先卖方至少 0.2、高收益质量门槛通过、买方总分至少 0.6，以及入场风险计划允许。SELL 需要至少两组独立 L1 证据、卖方基础分至少 0.5、卖方基础分领先买方至少 0.2；不使用高收益的反概率。方向差额只比较 L1 基础分，质量加分不能消除方向分歧。

均线辅助结构与均线属于同一依赖家族，同向取最大贡献，只有辅助结构时仍按结构权重计分；家族内部反向意见弃权。每个 Agent 每日最多贡献自己的权重，重复或混合来源事件不会增加权重。

例如，独立结构与威科夫均支持买入、均线弃权、高收益通过时，基础 0.5 加质量 0.1 达到 BUY 0.6；若均线反向卖出，基础差额只有 0.1，仍为 WAIT。独立结构与威科夫支持卖出、均线弃权时，SELL 基础 0.5 达到门槛。均线与均线辅助结构支持买入，仅构成一组独立证据，不能生成 B。

仲裁状态为中性、看多、看空，表示研究方向。同方向候选不会每日重复出票；原证据过期、出现未消费的新机会且满足冷却后才允许重新出票。完整历史先计算，再截取显示窗口，改变图表开始日期不会重置方向或制造新点。

## 调参数与复现

配置文件是 `my_strategy/configs/czsc_agent_consensus.json`，通过公共配置加载器读取；自定义配置根目录使用 `KHQUANT_CONFIG_ROOT`。默认值：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| version | czsc_agent_consensus_v2 | 加权方向支持与买入质量加分版本 |
| source_weights | MA 0.4 / 结构 0.2 / 威科夫 0.3 | L1 基础支持权重，同依赖家族去重 |
| high_return_quality_weight | 0.1 | L2 通过门槛后固定买入质量加分，非独立票 |
| min_buy_base_support | 0.5 | 买入最低 L1 基础分 |
| min_buy_support / min_sell_support | 0.6 / 0.5 | 买入最低总分 / 卖出最低基础分 |
| min_direction_margin | 0.2 | 胜出方向与另一方向 L1 基础分最低差额 |
| min_independent_families | 2 | 胜出方向最低独立正权重 L1 家族数 |
| ma_entry_threshold | 0.55 | 保存的 MA 入场概率门槛 |
| wyckoff_min_strength | 0.5 | 当日量价规则强度门槛 |
| high_return_threshold | 0.1 | 图表仲裁的 L2 买入过滤门槛 |
| require_high_return_when_family | true | v1 高收益方案闸门设置；v2 买入始终要求有效 L2 |
| signal_valid_bars | 20 | 同方向证据有效期 |
| cooldown_bars | 5 | 同方向重新出票最短间隔 |

这些默认值是本次图表仲裁参数，没有新增收益最优的验证结论。调整后重新发起分析即可生效。参数作用于已经通过第一阶段资格的候选，仍须满足原模型和风险计划资格。高收益权重 0.1 与模型概率门槛 0.1 是两个独立参数；前者表示 10 分贡献，后者表示模型概率至少 10%。支持分不代表预计收益或获利概率。

已保存的分析和历史重新判断请求绑定当次有效配置、配置哈希与仲裁版本，后续改文件不应改变旧请求的判断口径。API `/api/analysis` 接受可选 `consensus_config` 和 `consensus_version`；新请求默认 v2，旧 v1 完整有效配置自动识别 v1。显式 v1 使用原等权默认值和原仲裁行为，不读取 v2 默认值；版本冲突、未知或不可达参数明确拒绝。点击打开旧保存结果仍显示原票数，历史重判也绑定其原版本。

结果的 `consensus_decisions` 保存最终点、每日意见、实际基础贡献、质量加分、买卖基础分、买入总分、独立证据数量、状态、配置及历史预热范围；`chart_evidence` 和原始 `signal_points` 保存来源证据。买入满分 1.0，卖出基础满分 0.9，实际门槛始终按配置原始分比较，不对缺失评分归一化。未提供独立逐日证据或兼容高收益评分的模型方案不能生成新的 v2 买点。

## 实际交易边界

本功能是可复现的研究判断，未改变原 Position/Broker 执行、模型训练、标签、检查点或发布资格。参考价使用信号可知当日收盘价；收盘信号不代表同日收盘成交。实际执行价、费用、拒单和真实持仓退出以 Broker 账本为准。

如果要把新的仲裁政策接管实际交易，需要单独冻结政策、重放完整费用后账本，核验目标兼容性；目标改变时重新生成标签和训练，并完成独立窗口审计。
