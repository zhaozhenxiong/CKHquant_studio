# 图表多 Agent 买卖点

主图的 B（买点）与 S（卖点）来自独立的市场方向仲裁。三路原始候选仍保留，只有通过仲裁且未被重复抑制的点显示在图上。

## 查看方式

鼠标移动只更新十字线、均线/布林带读数和所选历史日期的120日量价分布。点击 B/S 或带有最终点的 K 线才打开判断窗口；点击空白 K 线、关闭按钮或按 Esc 关闭。移动鼠标不会重新打开窗口。

窗口先显示当日最终结论和仲裁原因，再列各 Agent 的意见及当日保存的评分；原始候选放在可展开明细中。没有最终点的日期可在“按历史时点重新判断”的历史表查看 WAIT 及原因。

日线最终点是唯一来源。周线、月线按原始日期归入对应周期，同一周期最多一个 B 和一个 S；同周期存在真实的不同日期方向变化时保留两种标记。v3 中，已确认日线点立即投影到形成中的周/月柱，注明“周期形成中，日线点已确认”；原生周/月信号仍须等待周期闭合。点开后查看全部最终事件、首次可用时间和原始日期。周期合并不重新训练或重新投票。

标记位置用于区分方向，参考价取实际信号日收盘。只有点击最终点后才显示参考价水平线和点；关闭窗口、点击空白、按 Esc、切换周期或重新加载时清除。结构锚点与确认日分别显示，买卖点不会移回尚不可知的结构日期。

## 判断链路

1. **候选触发**：均线、结构、威科夫任一路出现当日可见且输入合格的新候选，启动共同评估。原始事实、方向支持与实际入场风险资格分别保存；风险不合格的原始事实仍可解释方向。
2. **均线 ML**：评估同一候选的当日因果趋势和完整身份核验后的模型概率，允许当日没有新均线事件。使用原冻结训练运行重新计算并核对原候选/事件哈希，恢复完整日线评分及 manifest、目标、schema、策略和风险身份；额外推理量单独记录。模型概率不延续到下一日。趋势失效卖方证据需要真实已知失效事件和当日弱势确认，不能由买入反概率推断。
3. **CZSC 结构与威科夫量价**：当日候选或仍有效的既有事件，在当日重新核验支撑/阻力、结构确认时间、价格边界和当前供需强度。默认使用含当日在内最近3根实际日线；失效证据不复活。依赖均线的结构与均线归为同一证据家族，规则强度不转换成获利概率。
4. **高收益区间 ML**：进一步过滤已有买入候选，要求同日兼容评分及原风险计划。通过质量门槛固定增加买入质量分 0.1，不增加独立证据数量，不支持 SELL；没有兼容的当日评分时不能凭最新评分补过去日期。
5. **仲裁 Agent**：按去相关证据家族计算买卖支持，执行门槛、冲突、风险及重复过滤，输出 BUY/SELL/WAIT、理由和来源事件身份。

默认 v3 使用均线 0.4、结构 0.2、威科夫量价 0.3、高收益质量分 0.1。前三路通过各自门槛后给对应方向贡献固定权重；模型概率和量价强度仍单独展示，不相乘、不混合成获利概率。缺模型或不可见证据属于弃权，剩余权重不重新分配。

BUY 需要至少两组独立 L1 证据、买方基础分至少 0.5、买方基础分领先卖方至少 0.2、高收益质量门槛通过、买方总分至少 0.6，以及入场风险计划允许。SELL 需要至少两组独立 L1 证据、卖方基础分至少 0.5、卖方基础分领先买方至少 0.2；不使用高收益的反概率。方向差额只比较 L1 基础分，质量加分不能消除方向分歧。

均线辅助结构与均线属于同一依赖家族，同向取最大贡献，只有辅助结构时仍按结构权重计分；家族内部反向意见弃权。每个 Agent 每日最多贡献自己的权重，重复或混合来源事件不会增加权重。

例如，独立结构与威科夫均支持买入、均线弃权、高收益通过时，基础 0.5 加质量 0.1 达到 BUY 0.6；若均线反向卖出，基础差额只有 0.1，仍为 WAIT。独立结构与威科夫支持卖出、均线弃权时，SELL 基础 0.5 达到门槛。均线与均线辅助结构支持买入，仅构成一组独立证据，不能生成 B。

仲裁状态为中性、看多、看空，表示研究方向。同一机会只出票一次；不同的新机会满足支持门槛及同方向冷却后可以再次出票。没有当日新候选，只有历史证据时不出票。完整历史先计算，再截取显示窗口，改变图表开始日期不会重置方向或制造新点。

## 调参数与复现

配置文件是 `my_strategy/configs/czsc_agent_consensus.json`，通过公共配置加载器读取；自定义配置根目录使用 `KHQUANT_CONFIG_ROOT`。默认值：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| version | czsc_agent_consensus_v3 | 同候选评估与有限期当日重新核验版本 |
| source_weights | MA 0.4 / 结构 0.2 / 威科夫 0.3 | L1 基础支持权重，同依赖家族去重 |
| high_return_quality_weight | 0.1 | L2 通过门槛后固定买入质量加分，非独立票 |
| min_buy_base_support | 0.5 | 买入最低 L1 基础分 |
| min_buy_support / min_sell_support | 0.6 / 0.5 | 买入最低总分 / 卖出最低基础分 |
| min_direction_margin | 0.2 | 胜出方向与另一方向 L1 基础分最低差额 |
| min_independent_families | 2 | 胜出方向最低独立正权重 L1 家族数 |
| ma_entry_threshold | 0.55 | 保存的 MA 入场概率门槛 |
| wyckoff_min_strength | 0.5 | 当日量价规则强度门槛 |
| high_return_threshold | 0.1 | 图表仲裁的 L2 买入过滤门槛 |
| require_high_return_when_family | true | v1 高收益方案闸门设置；v2 买入始终要求有效 L2 |
| signal_valid_bars | 20 | 同方向证据有效期 |
| cooldown_bars | 5 | 同方向重新出票最短间隔 |
| evidence_valid_bars | 3 | 事件有效日线窗口；允许1、3、5，包含当日；实际日线计数 |

这些默认值是本次图表仲裁参数，没有新增收益最优的验证结论。调整后重新发起分析即可生效。最终 BUY 仍须满足原模型和当日风险计划资格，15%止损距离上限保持。高收益权重 0.1 与模型概率门槛 0.1 是两个独立参数；前者表示 10 分贡献，后者表示模型概率至少 10%。支持分不代表预计收益或获利概率。

已保存的分析和历史重新判断请求绑定当次有效配置、配置哈希与仲裁版本，后续改文件不应改变旧请求的判断口径。API `/api/analysis` 接受可选 `consensus_config` 和 `consensus_version`；新请求默认 v3，旧 v1/v2 完整有效配置自动识别原版本。显式 v1/v2 使用其冻结默认值与原仲裁实现，不读取 v3 默认值；版本冲突、未知或不可达参数明确拒绝。点击旧保存结果仍显示原评分，历史重判绑定其原版本。

结果的 `consensus_decisions` 保存最终点、每日意见、实际贡献、质量加分、独立证据、当前证据年龄、状态、配置和历史预热范围；`chart_evidence` 和原始 `signal_points` 保存来源证据。买入满分 1.0，卖出基础满分 0.9，门槛按原始分比较，不对缺失评分归一化。未提供完整当前证据或兼容高收益评分的模型方案不能生成新的 v3 买点。

v3 的每日 `funnel` 与总 `diagnostics` 保存原始事件、可见事实、新候选、有效方向证据、独立家族、L1通过、风险通过、质量通过及最终出票数，另有原因计数。各阶段含不同方向、不同统计单位，不能相减当作互斥淘汰数；单日详情可定位 WAIT 原因。

## 离线成交诊断

从项目根执行：

```sh
PYTHONPATH=app .venv/bin/python -m my_strategy.scripts.validate_candidate_consensus --symbols 002436.SZ 600519.SH 000333.SZ --end 2026-10-09 --device cpu
```

对 v2 与 v3 的1/3/5根窗口使用真实日线、核验日历及 Broker；按次日开盘、原风险计划、真实费用、滑点、止损、T+1与60日最大持仓规则执行，WAIT保留仓位。每股票每窗口独立10万元账户，比较标准及双倍滑点，保存账本、每日净值、拒单和报告。2025Q2/Q4、2026Q2/Q3及2026YTD仅作开发诊断。

此实验以最终S作为退出条件，与冻结L2标签的续持政策不同，报告明确 `l2_continuation_contract_matches=false`。不能凭该结果宣称原L2目标已经匹配新成交策略、获得晋升资格或实现高收益；独立验证保持 pending。

## 实际交易边界

本功能是可复现的研究判断，未改变原 Position/Broker 执行、模型训练、标签、检查点或发布资格。参考价使用信号可知当日收盘价；收盘信号不代表同日收盘成交。实际执行价、费用、拒单和真实持仓退出以 Broker 账本为准。

如果要把新的仲裁政策接管实际交易，需要单独冻结政策、重放完整费用后账本，核验目标兼容性；目标改变时重新生成标签和训练，并完成独立窗口审计。
