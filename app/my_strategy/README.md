# CZSC 量价研究工作台 0.1.6

当前分析链路是原始 SQLite 日线 → 已知时点的 CZSC 结构、均线和量价证据 → 来源 B/S 与最终共识 B/S → 独立风险及合格仓位参考。分析与扫描不执行资金账户回放，不把收盘参考价当成交价；需要实际持仓前缀的退出概率在无账户参考页面保持不可用。

六页面为结构分析、全市场扫描、我的关注、模型训练、参数设置、数据与任务。资金/成交账本、策略回测、手动持仓及专用入口已删除。关注与扫描星标统一持久保存。行情、结果、任务与关注分别落在配置的业务路径中，不写 site-packages。

当前内部策略为 `trend_consensus`，基准配置为 `configs/czsc_trend_strategy.json`，公开选择为 `configs/current_strategy.json`。三分类趋势、结构、量价与质量按冻结配置共识；缺模型不补零，未评分原因单独披露。来源 S 不必满足最终 S 门槛，最终门槛仍原样核验。

训练内部保留真实 Broker、下一核验开盘尝试、T+1、费用、拒单及完整清仓标签。三分类正温度校准保持类别排序；第二层退出使用预登记 E1 实际持仓配对，入场保持严格先验实际空仓尝试。参考质量另用独立真实人口、头与费用证据；风险仓位上限不替代合格目标。

先准备自己的行情和已核验日历，再在训练中心预检、提交、查看阶段进度与诊断。支持的线性/MLP 可以使用明确 MPS/CUDA；CZSC、三分类方向、树模型与真实 Broker/state 在 CPU。旧模型已退役，公开包不带权重或选择指针，缺合格选择保持未评分/pending；软件发行不授予独立收益资格。

运行 `python -m my_strategy.cli --help` 或 `khquant --help` 查看当前入口。所有相对业务路径以应用根为基准，由 `core.paths` 和环境配置解析。文档见 [训练指南](docs/current_model_training.md)、[参考分析](docs/reference_analysis.md)、[B/S 与仓位](docs/bs_position_reference.md) 和 [根目录安装说明](../../INSTALL_NATIVE.md)。历史审计仅供查证，不能作为恢复退役模块的指令。
