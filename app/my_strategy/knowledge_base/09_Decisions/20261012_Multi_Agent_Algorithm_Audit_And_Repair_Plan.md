## 二、要达到的行为

任一路产生真实的新候选后，所有Agent评估同一个当日候选。候选事件的新鲜度、持续结构状态的有效期、模型适用范围、风险资格和实际成交各有独立记录。

- 均线Agent返回趋势状态、战术转弱及适用范围内的入场质量，不能由 `1-p_buy` 产生卖出概率。
- 结构Agent使用已确认的纯结构及当前仍有效的支撑/阻力，提供独立判断；均线辅助结构继续标明依赖。
- 威科夫Agent分别展示当日量价支持和已确认/待测试事件证据，需求与供给分别维护。
- 高收益Agent只对目标覆盖的人口提供第二阶段概率；未评分必须有明确原因。
- 仲裁保留40/20/30/10为对照，不通过重分配缺失权重或取消依赖去重增加分数。策略变化采用新仲裁版本，旧v1/v2/v3快照按原口径回放。

主图保持最终B/S；威科夫原始事件由单独图层开关控制。点击才出现Agent判断与参考价，悬浮仍只更新指标和量价分布。

1. 从已经计算的完整威科夫特征输出展示事件，统一事件类型、身份、原观察时间、首次可用时间、状态、是否确认及原因字段。待测试SOS与已确认LPS分别显示。
2. 日线输出全部可见事件；周/月按首次可知日期归桶，聚合相同类型和方向，点击展开原日期。形成中高周期明确注明日线证据已经可知，原生高周期信号仍遵守闭合规则。
3. 历史表与弹窗共用当前证据视图：原始方向事实、风险资格通过数、当前结构意见、有效历史支持和最终贡献分别显示。
4. 概率状态统一为：无候选、风险阻止未评估、输入不合格、缺兼容模型、已经评分未过门槛、已经评分通过、真实身份错误。`null`不改成0；中性规则分0不改成数据缺失。

## 四、P1：修正事件身份、时钟和失效边界

1. 结构机会身份绑定规则版本、完整确认模式、锚点及首次确认时刻。状态延续、价格更新、风险拒绝与资格变化另存每日评估，不能刷新原事件出生日期。
2. 分开两种用途：触发新候选要求真实新模式/确认；当前结构支持在已有其他来源新候选上评估，可持续至价格或反向确认使其失效。不能用拉长候选TTL来代替结构状态建模。
   风险资格首次从不合格变为合格时，可以在新政策中单独定义“资格激活候选”，保留原模式确认时间，记录真实激活日期、独立转换身份及一次性限制；它不是结构再次确认。此规则须纳入新标签和回放契约，避免漏掉合理的较晚入场，也避免每日重复触发。
3. 元数据拆成原事件 `origin_observed_at / first_available_at` 与当前 `snapshot_at / available_at`；保留原日期，不把历史观察日期改成今天。
4. 为各W事件保存专属冻结边界、确认条件、破坏条件、当前价格和过期原因。Spring、SOS/LPS与SOW/LPSY不能统一用60根大区间低/高点复核。
5. 分开事件失效线、入场风险止损和实际持仓退出政策，记录各自用途及因果来源。明确失效不能复活；无来源、过期和失效不是同一种状态。

关键回归：

- 6月4日辅助结构原确认5月11日，已有18根日线，不能被6月2/3/4日风险拒绝当作三次新确认。
- 6月4日LPS原风险止损38.7632、冻结突破支持约40.20；6月5日收37.90已破坏支持。即使衰减需求95分，也不能恢复买方支持。
- 6月25日收53.53，高于前一LPS支持/止损，需求95分；应按真实原边界和当前快照核验，不能仅因当天没有新事件的 `observed_at` 就弃权。它是否形成最终B仍由新候选、适用模型、风险和仲裁决定。
- 相同机会只触发一次，显示起点变化不能重生机会；截至某日计算必须等于完整历史严格截断后的结果。

产物：事件账本、每日评估账本、生命周期和版本契约、1/3/5根窗口独立重建比较。

## 五、P2：实现真正独立的结构和当日量价专家

### 结构

已只读验证compiled原生算法可调用：一买/一卖不使用MA；纯第二买卖点 `V240524` 不使用MA；纯笔三买 `V230228` 仅提供BUY。2026样本出现一卖33个状态日、二买26日/二卖1日、三买74日，但这些持续状态不能直接转换成同数量的新点，也不能虚构三卖镜像。

按完整因果前缀逐日推进，仅使用已确认笔、分型、中枢与原生模式；连接纯结构生产者并记录依赖跨度和首次可知时间。辅助BS2/BS3继续归入MA家族。审计最新形成中中枢与仍有效已确认中枢的选择规则，避免因最新中枢不足3笔就丢掉全部历史结构上下文。

另行定义结构失效卖出：支撑被破坏、确认反向结构及其首次可知时间。新卖点和真实持仓退出分别保存；不能把历史高点回填为当时已经知道的卖点。

### 威科夫

保留旧事件衰减强度作为对照；新增当前日量价判断，使用当日已经发生的价格区间、收盘位置、相对成交量、放量涨跌、缩量回踩、供给释放和需求恢复，归一化与窗口只用历史数据。

分别保存当日需求/供给支持、事件确认强度、事件状态和来源有效期。支持趋势、震荡、回踩及转弱场景，避免只靠最近一次60日箱体事件决定所有日子的量价意见。新评分的公式、量纲、门槛与schema先冻结，再在同一候选上评估；它不是获利概率。无充分证据允许中性或弃权，不能为了填满页面产生数值。

产物：纯结构生产者、结构上下文快照、新量价评分契约及真实日期反例集。验收涵盖上涨、震荡、下跌和反向确认，独立来源不得读取MA判定或最终仲裁结果。

## 六、P3：修正MA适用范围、风险政策与L2训练链

1. MA每天都有概率只证明能推理。新增 `candidate_envelope / in_scope`，分开原MA机会上的有效分与尚未验证的跨来源研究分。10月9日84.71%同时处于转弱状态且没有新候选，不能解释成有效买点。
2. 对原MA、纯结构、W和候选并集分别检查特征分布、前向校准、标签和实际交易结果。需要跨来源给完整40%时，使用覆盖新人口的训练/校准目标，不能仅因模型哈希完整就取得资格。
3. 保留当前15%上限为风险对照，做按来源的因果止损消融：已确认回踩/支撑、事件专属边界、ATR与仓位预算。记录被拒绝事件、拒绝原因和机会成本；新止损不能为事后选点服务。
4. 冻结新候选人口、事件前缀、风险、费用和续持/退出政策后，用真实Broker生成新标签。若改变这些内容或特征schema，必须新研究版本、新标签、新模型和新校准，旧产物不改写。
5. MA独立退出依赖继续按既定流程：无入场头的规则bootstrap、独立退出头、严格前于候选且信号时固定的退出头重新生成MA入场目标，再产生前向L1分数和L2区间标签。拒单、未完成回合与未成熟退出不标成失败样本。
6. L2目标仍明确为完整费用后收益与初始风险倍数。分别展示质量权重和概率阈值；对统一阈值、原fold阈值与校准选择做预先定义的开发比较。风险不合格候选保留方向及原因；若另提供风控前研究概率，需要新的适用目标与模型，不能拿旧头补空值。

产物：冻结协议、候选覆盖表、数据与模型谱系、标签与校准报告、同政策实际成交账本。当前旧L2不能直接认证新增纯结构机会或新的退出策略。

## 七、P4：更新仲裁并完成系统验收

新候选触发一次共同评估，角色意见使用当前快照。买方与卖方的支持、源内冲突、依赖合并、风险阻止及质量拒绝分别解释。MA长趋势与短期转弱分开建模，明确互斥状态或预先定义的优先政策，保留9月30日为冲突反例。

默认40/20/30/10作为首个对照。高收益仍只筛选已有BUY，不参与SELL，也不把缺概率补成0。真实账户硬止损与强制退出按Broker优先规则执行；图表方向点不能代替实际平仓账本。

验收顺序：

1. 兴森科技真实案例及美的、贵州茅台对照；再扩展冻结样本覆盖不同走势、缺口和停牌，失败样本保留。
2. 各来源从原始输入到事件、每日支持、风险、模型和仲裁的逐日可重算验证；所有空值有明确原因。
3. 相同模式不重复生成新事件，确认日/可用日/参考价/高周期投影一致，无未来信息。
4. 旧v1/v2/v3结果保持可复现；图层、点击弹窗、历史表与实际API一致，浏览器无错误。
5. 1/3/5窗口各自重建当前评估；逐步消融展示修复、时钟修复、纯结构、连续量价、MA范围、风险和L2，不能混用输入把变化全部归功于仲裁。

7. 已读季度与2026YTD仅为开发诊断。新代码/协议/配置/模型真正冻结后才能启动既定独立窗口；未成熟保持pending，不以增加买卖点数量或单次收益认证模型。
