# 加权图表仲裁 v2

2026-10-12，用户授权将图表多 Agent 仲裁改为均线 0.4、结构 0.2、威科夫量价 0.3、高收益质量分 0.1，并完整执行确认的计划。

前三路使用已有、可见、合格的当日候选，通过各自资格门槛后贡献固定方向分。L2 只评估已有 BUY 候选；通过当前兼容质量门槛后固定增加 0.1，既不作为独立 L1 家族，也不支持卖出。保存的原模型概率、规则强度与贡献分分别记录。

BUY 要求至少两组独立正权重 L1 家族、基础分 >=0.5、总分 >=0.6、基础方向差 >=0.2、有效 L2 和原入场风险计划。SELL 要求至少两组独立正权重 L1 家族、基础分 >=0.5、基础方向差 >=0.2。缺失证据不重新分配权重。数值边界按明确精度处理。

事件按依赖去重；均线辅助结构不能与均线累计贡献或增加独立家族。家族同向取最高权重，内部反向弃权，每个 Agent 每日贡献不超过自己的权重。原机会身份、完整历史预热、方向持续、冷却、参考价与信息可见性检查继续适用。

新请求默认 `czsc_agent_consensus_v2`。旧完整有效配置与显式 v1 请求由原逻辑重判；新默认文件不能改变旧配置哈希与决策。保存请求绑定有效配置和版本，前端加载保存结果及历史重判传递相同身份。旧 v1 展示票数，新 v2 展示基础分、质量分、门槛、独立家族和实际贡献。

本次范围为图表市场方向研究仲裁与解释窗口。权重不是获利概率，不改变模型训练目标、冻结模型、原始候选或 Position/Broker 的实际交易政策。实际费用后交易绩效仍依据原账户账本；历史仲裁比较属于开发诊断，不能作为独立收益审计或模型晋升证据。

验收包括批准的数值样例、缺失及不兼容 L2、依赖去重和冲突、精度边界、完整前缀与 as_of 因果性、v1 结果复现、API 版本契约、日周月点击展示、悬浮不打开窗口，以及真实行情与冻结模型只读完整性核验。操作与参数说明见 `my_strategy/docs/agent_consensus.md`。
