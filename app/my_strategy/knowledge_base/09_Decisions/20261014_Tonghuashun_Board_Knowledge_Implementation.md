# 同花顺当前板块知识库实施说明

本次在独立工作树实施当前板块知识库、最新行情的参考特征缓存和板块工作台。用户最新范围仅补现在的板块特征，不抓取历史归属、不补过去成员变化，不生产历史特征或接入训练。原计划见同目录 `20261014_Tonghuashun_Board_Knowledge_And_Feature_Plan.md`，其中历史训练设想已移出本次任务；执行范围以本说明和当前用户要求为准。本说明记录已经实现的边界和操作方式，不把目录已发现、正在采集或软件测试通过写成全量资料完成。

## 当前来源及完成状态

用户确认目前没有同花顺历史成员接口权限或历史导出，因此首版仅积累当前可观察事实。实际采集使用扶摇 API 提供的同花顺指数目录及当前成员：

- `source = fuyao:ths`，`taxonomy = THS_INDEX`。
- 行业身份示例 `THS_I_881155.TI`；概念身份示例 `THS_C_885338.TI`。保留来源完整 `.TI` 代码和名称。
- 2026-10-14 已验证的目录范围为 320 个行业指数、390 个概念指数，共 710 个目录项。全量当前成员已核验入库 710/710，80,725 条 A 股成员关联，覆盖 5,581 个不同股票。基本资料从原库复制 5,572 只；归属覆盖数与基本资料人口分别记录。
- 原始价格继续读取既有行情库；扶摇接口本轮只提供板块目录和成员，不替换行情数据。新浪申万、东财概念及旧混合提供器不冒充此来源。

当前接口只给行业指数代码和名称，没有已核验的行业层级。一只股票可以同时匹配多个行业指数；查询保留全部归属，不按名称、代码排序或收益强弱擅定唯一主行业。个股相对行业、同行分位等在归属歧义时保持缺失，并给出“行业指数层级尚未核验”的说明。板块自身的 12 项指标仍可按各个指数分别计算。

来源完整成员与本地 A 股指标人口分别记录。若来源包含本地行情契约不支持的市场，例如三胎概念的 213 个来源成员中有 `834683.NQ`，保留原始 213 成员的双响应、完整集合及哈希证明，再明确标识 `membership_scope=a_share_projection_v1`、`source_member_count=213`、`excluded_source_members=[834683.NQ]`，A 股投影成员及覆盖分母为 212。默认未投影板块显示 `membership_scope=source_full`。排除清单不能静默删除或伪称来源只有 212 人；不为 NQ 成员构建或填补成交指标，也不把它放入 A 股指标覆盖分母。

来源响应必须具有成功业务码、请求标识、来源时间、原始内容 SHA，以及重复读取一致的目录和成员集合。完整成员列表不能靠去重后的部分结果推定；经过完整性证明的空成员与请求失败分开处理。超出请求预算、权限、限流或网络中断留下明确状态，已有完整成功记录保持可读。

## 存储和时间边界

路径由 `core.paths.BASIC_KB_DB_PATH` 解析，默认 `DATA_ROOT/raw/stock_basic/basic_kb.db`。原始行情库按只读连接读取，股票代码映射在读入数据中规范化，不修改原行情表。

实施表为 `stock_basic`、`board_catalog_versions`、`board_snapshots`、`board_membership`、`source_payloads`、`board_daily_features`、`stock_board_features`、`board_refresh_runs`。目录、成员、来源响应和特征结果追加保存，完成的刷新记录与成功快照不被失败批次覆盖。同输入重复导入保持幂等，SQLite 使用 WAL 和事务；页面读者使用只读连接，缺数据库的只读查询不创建文件。

每份成员事实保留 `observed_at`、`available_at`、`effective_at`，并保存来源响应时间与实际获取、入库边界。当前数据的可用时间至少受实际获取和导入时间约束；来源给出的早日期或手工填写的旧时间不能把本轮当前快照变成历史事实。成员变化的观察时刻不冒充真实加入、退出时刻。

生产仅使用 `current_reference`，行情日取最新来源合格的本地价格。数值服务仍保留内部因果拒绝门槛，用于验证当前成员不会被误用到过去；这不代表本轮生产历史结果。

| 模式 | 读取与用途 |
| --- | --- |
| `causal`，内部安全校验 | 每个依赖日仅读取该日 15:00 已观察、已可用且已生效的成员；当日价格须有真实合格观察，不能用较早报价补替。仅用于无缓存的防误用检查，不生产历史特征。 |
| `current_reference` | 用当前观察成员回看截至指定行情日的价格，仅提供展示诊断。分别标明 `membership_date`、`price_date`、来源时间及覆盖，始终 `training_eligible=False`。 |

例如，2026-10-14 新取得的成员可以对本地最新 2026-10-12 行情形成当前成员口径的参考，但不能成为 2026-10-12 模型的因果输入。复制缓存或手工改资格标记不能跳过内部读取拒绝门槛。当前参考永远不是历史成员标签或历史训练输入。

## 已实现的公式和缺失语义

板块日指标采用存储的、来源合格的未复权行情，属于等权研究摘要，不是官方板块指数、总收益指数或实际成交账户：

| 指标 | 冻结口径 |
| --- | --- |
| 1、5、10、20 日收益 | 各依赖日可见成员的合格简单日收益等权平均，再按核验交易日连乘。当前参考模式单独标识为当前成员历史回看。 |
| 上涨比例 | 当日简单收益严格大于零的合格成员比例。 |
| MA20 比例 | 当前收盘严格高于包含当日在内的 20 日收盘均值。 |
| 前 20 日创新高比例 | 当前收盘严格高于此前 20 个核验日最高价，不包含当日高点。 |
| 成交额、金额占比 | 合格成员成交额之和，及其占本地合格可观察 A 股成交额之比；沪深 B 股不进入该分母。金额单位 CNY。 |
| 相对成交额 | 当日板块金额除以前 20 日板块金额均值，分母为零或依赖缺失时不可用。 |
| 20 日波动 | 20 个完整板块日收益的样本标准差乘以 `sqrt(252)`。 |
| 20 日回撤 | 20 日等权研究收益路径的最大峰谷回撤，路径包含初始净值 1。 |

默认先冻结 `min_members=5`、`min_coverage=0.8`。每项指标分别记录有效成员数和覆盖率；成员不足、覆盖不足、未核验来源、缺真实交易价格、重复报价或报价晚于决策时点均不能补成零。小板块和剔除自身后同业过少须明确显示不可用。

个股侧固定一行一个股票，同行比较剔除自身；相对行业 1、5、20 日收益是个股完整区间收益减去同行每日等权组合的区间收益。20 日同行分位按低于该股的有效同行比例及一半并列值计算。多个概念汇总为同行概念的 1、5、20 日平均收益、平均上涨比例、20 日正收益概念比例和已知概念数，不展开为重复训练样本。未采到概念不能解释成已确认没有概念。

已提供独立 `tonghuashun_board_context` profile 和有序 22 列个股参考指标。内部读取门槛核验模式、当日价格、可用时间、完整窗口、schema、冻结政策、来源和依赖身份，拒绝当前参考冒充训练输入；本轮不追加模型输入，也不授予模型或收益认证资格。

## 缓存和性能边界

每日批量结果通过 `daily` 缓存保存 `boards`、`stocks` 两组扁平行。板块或个股页面从已保存批量结果中读取匹配行；普通 GET 查询不发远程请求，也不重建全市场特征。

缓存键绑定模式、行情日、最近 41 个核验日的实际价格内容及行数、21 日成员快照依赖、截至行情日的日历前缀、价格基础、覆盖政策、公式/profile/schema、生成源码身份及请求股票范围。41 日价格依赖用于同时承接板块滚动窗口和成员的 MA20、前 20 日高点条件。

相同身份直接返回原缓存结果，仍先读取并核验价格和成员依赖；缓存命中不等于省略来源核验。后来的交易日和未使用的未来报价不改写历史结果，依赖区间内修订产生新缓存身份。超出本日实际价格依赖的旧价修订不迫使该日重算。旧版本保留，不原地改写结果。

当前实现使用板块逐日汇总量以及剔除自身后的分母、合计值计算同行组合收益和比例，不为每个概念同行组合重新扫描全体成员。股票归属已改为从每条成员关联建立一次反向索引，替代“每只股票逐板块扫描成员列表”；保持原快照顺序、股票排序和浮点计算路径。以股票数 S、成员关联数 E 表示，该部分从最多 O(S×E) 扫描变为 O(E+S) 索引和查找，股票输出排序口径不变。行业分位仍逐股比较同行，多个行业归属保持歧义并不执行唯一行业分位。首轮全量成本仍包括价格读取、成员验证、概念关联汇总和结果序列化；不能从小样本测试推断 710 个板块全量耗时。不得为提高吞吐绕过重复来源、时间、完整性或 SHA 核验。

2026-10-14 的隔离真实小样本检查使用 3 个已核验板块：一个 3,878 成员概念、两个 29 和 42 成员行业，共 3,949 条成员关联及 3,890 个不同股票。读取正式行情库的只读 41 日窗口，共 227,475 行，行情日为 2026-10-12，日历为已核验运行 `20261010-111442-245667-20261009-czsc-verified-calendar-NO_GIT`。缓存只写入审计目录的 `smoke-basic-kb.db`，不写正式知识库。

该次带 `cProfile` 采样的首次构建为 12.390 秒，进程最大常驻内存约 484 MB；相同依赖的缓存命中读取为 2.498 秒，返回结果完全一致。全部板块及股票参考行的训练资格均为 false，整体资格保持 pending。采样中行情读取及准备约 5.286 秒，其中 SQL 读取约 2.209 秒、17 位精度价格内容序列化约 2.063 秒；9 个矩阵转换为查找字典约 2.884 秒。这是单次真实小范围诊断，包含采样开销，不是 710 板块全量耗时或生产吞吐承诺。

反向索引改动后，原 20 项检查及因果、当前参考两种模式的原扫描等价检查共 22 项通过。相同真实小样本的新结果与上一版已保存结果在移除生成码和缓存键身份后，全部字段精确相等；改动后的源码身份形成独立缓存键，不放宽跨版本复用。后续带采样的强制数值重算为 10.897 秒，其中反向索引构建约 0.001 秒，进程最大常驻内存约 505 MB；实际缓存命中为 2.645 秒，结果完全一致。该强制重算不包含新缓存首次插入，不能与上一计时直接推算百分比提速。完整 710 板块构建仍须等成员采集结束后另行测量和验收。

## 三条 CLI 和工作台

以下从应用根执行，使用项目配置的 Python 环境；路径和核验日历可通过参数显式指定。

```bash
python -m my_strategy.cli refresh-board-knowledge --kinds industry concept --limit-budget 2000

python -m my_strategy.cli build-board-features --mode current_reference --calendar-run-id <核验日历运行ID>

python -m my_strategy.cli board-workspace --host 127.0.0.1 --port 8125
```

`refresh-board-knowledge` 可用 `--db`、`--raw-db` 指定知识库及只读基本资料来源，用 `--resume <刷新ID>` 继续未完成目录；已完成的 manifest 不改写，剩余任务形成新刷新。`--import` 只接受具有同样来源、完整性及时间证明的 JSON 快照。

`build-board-features` 可用 `--kb-db`、`--raw-db`、`--symbols` 限定输入，`--json` 输出完整结果；本轮生产模式为 `current_reference`，仅取最新来源合格的本地行情日并核对日历。`--no-cache` 用于明确的当前指标重新计算检查，不改变训练资格。

工作台地址为 `http://127.0.0.1:8125/`，可以查看行业/概念目录、股票归属、已缓存指标和刷新任务。`GET /api/boards/status` 返回真实库覆盖和最后刷新状态。8125 工作台不持有或中断模型训练进程；更新资料通过显式操作启动，浏览页面只读取现有资料。
