# KHQuant CZSC 项目约定

应用根通过本文件与 `my_strategy/` 发现，不依赖固定盘符或构建宿主路径。当前公开模型体系为 `current`，内部策略为 `trend_consensus`；第三方 CZSC 保持冻结 1.0.1 来源及许可证。历史说明仅供查证，与当前架构冲突的菜单、身份或兼容要求不再适用。

## 当前架构

六个网页入口为结构分析、市场扫描、我的关注、模型训练、参数设置、数据与任务。面向用户的策略回测、资金/成交账本、手动持仓编辑及其专用 API/CLI 已删除，不恢复兼容入口。普通分析与扫描只输出无账户行情参考，不执行 Broker 回放；内部 Broker、Ledger、真实持仓配对和费用证据仅用于研究标签与资格验收。关注记录持久保存。

来源 B/S 与最终共识独立显示，均按当时可见证据处理。缺合格趋势头明确未评分，不能填零或拾取未合格候选。风险仓位上限不能冒充积极配置目标；独立参考质量人口、头、真实费用资格和原 BUY 风险/来源/价格/时点条件均通过才可生成正目标，缺资格保持 pending。可选用户仓位比例只作敞口比较，不进入模型或形成实际库存。最终 S 表示减少敞口，来源 S 本身不强制生成最终 S。

三分类校准仅拟合正温度，不使用类别截距改写排序。配置比较只在清洗后的训练内部时间段进行，校准与政策段不能参与配置选择。L2 入场使用严格先验实际空仓评分前尝试人口；退出与退出优势使用提前冻结的 E1 实际持仓配对，两实际分支均清仓才成熟。参考质量使用独立无账户输入及真实研究探针，不将 actual-flat 头改名取得新资格；该用途资格不新增核心自动选模的必需头条件。

旧模型及无用派生实体直接退役删除，不保留旧权重作为当前运行依赖。清理须保护原始行情、活跃任务的冻结代码/配置/来源、日历父链、关注与仍在写入的数据库。历史诊断事实及删除凭据可保留，不能恢复旧模型资格。运行中训练的生成文件和参数不得原地更改。

Native 准备使用有界逐股调度、分段计时、原子检查点与同 run 排他恢复；完整 closed/kas 历史保留。SQLite 结构缓存仅复用因果特征和 native 证据，键绑定原始内容、流动性、核验日历、输入契约、实际引擎、schema 与生成码。训练参数和进程数不改变结构输入身份；行情、日历、结构参数或代码改变须重建，新增交易日不作增量承诺。旧半成品不得冒充新来源检查点，取消与恢复按 attempt/父进程租约校验。模型、标签、费用、8%/2R、成熟和自动选择门槛保持。见 `my_strategy/docs/native_preparation.md`。

## 模块边界

- `adapters/czsc_adapter.py`：原始 SQLite 日线只读输入契约。
- `services/czsc_analysis.py`、`czsc_native_evidence.py`：冻结结构及因果来源证据。
- `services/czsc_trend_*`：当前趋势、实际研究人口、训练、推理与完整资格。
- `services/czsc_trend_runtime.py`、`czsc_reference_quality.py`：行情参考及独立参考质量。
- `services/czsc_backtest.py`、`execution/`：内部真实成交与标签核验，不提供公开回测产品入口。
- `web_dashboard/`、`storage/`：六页面、任务、当前结果索引与关注。
- `core/paths.py`、`config_loader.py`、`run_context.py`：唯一公共路径、配置和运行谱系。
- `vendor/czsc/`：冻结第三方源码，禁止无来源更新和测试的算法修改。

CZSC 结构、精确价格比较、三分类方向/树模型与真实 Broker/state 在 CPU；支持的线性/MLP 训练和神经批推理使用明确请求的 CPU/MPS/CUDA。MPS 结构价格比较保持 CPU float64，神经网络使用 MPS float32。不可用的明确设备不得静默回退；阶段实际设备需有报告，未报告不推断 GPU 使用或完成时间。

## 工作与审计

实现前读取相关源码、配置、测试及最新适用约定，明确可验证目标。修改前使用 `my_strategy/scripts/ai_change_logger.py start` 留下会话，结束使用 `finish` 追加事实、测试与限制；历史审计不得覆盖。架构修改按数据、模型、网页、存储、运维及审计边界协作。只修改任务必要内容，完成相应测试与真实输入检查，不能以进程存活代替成功。

## 时间、标签与门槛

- `as_of` 先截断输入，确认时间与结构锚点分别记录；历史不能回填未来结构、报价或模型。周/月闭合按已核验日历或下一周期真实观测判断。
- 参考价使用信号可知日收盘，缺价明确不可用；研究成交使用下一核验且可执行开盘。保留 T+1、整手、涨跌停、流动性、费用、拒单和期末未清仓状态。失败股票留在冻结人口分母。
- 高收益标签同时要求完整清仓费用后至少 8% 且至少 2R。拒单、未完成持仓和未成熟退出分支不能当负类。质量 0.1、总买方 0.5 及原买卖共识、风险、费用、类别与样本门槛不因展示或样本不足降低。
- 预处理仅拟合训练段，校准仅拟合校准段；标签在对应段截止前成熟。保持严格先验、原机会原子依赖清洗、目标/列顺序/schema、日历、来源与物理 SHA 核验。真实持仓固定信号时退出契约，不在途中升级。
- 完整人口、实际费用后基线/现任比较、费用压力及资产审计通过后才追加研究选择事件；默认推理只读取已生效且时点合格的选择。软件发行、目录名 production、训练完成与历史开发窗口都不能授予正式独立前瞻资格。
- 独立收益认证须绑定真实冻结后独立窗口，证据不足保持 pending；未复权、历史 ST、行业与成员资料不足明确披露。

## 路径、清理与发布

业务路径由 `.env` 和 `core.paths` 解析，运行使用独立 RunContext。新结果、任务与关注分库存储；关注不得混入研究成交账本。训练资源数据库的活跃租约不得删除或重建。清理列出精确目标并核验边界、引用、哈希与活跃状态，SQLite 关闭或在正确事务内操作。

正式 wheel 使用包内冻结资源，状态默认位于 `~/.khquant` 或明确配置的目录，不写 site-packages。公开源码 ZIP/wheel 不含行情、模型权重、研究账本、个人状态、秘密和本地审计提示词；构建宿主路径脱敏，来源与物理 SHA 保留。状态导出来自完整源码安装来源，wheel 用户用 `--from-project` 指定；导入模型不自动取得资格。测试强制隔离业务目录，不继承本机 `.env` 数据库。

完成时同步 CLI/API、任务、配置、文档与审计，验证真实入口、关注持久化、时间及资产资格，说明实际未验证的平台或限制。历史版本验证不能替代本次实际发行资产。
