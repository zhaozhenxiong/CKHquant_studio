# KHQuant 项目约定

## 当前产品合同

当前发行目标为 v1.0.1。应用根由本文件和 `my_strategy/` 发现，不依赖构建宿主路径。主站五个入口为结构分析、全市场扫描、我的关注、预测与回测、数据与任务。旧 `reference_position_v1` 只作为明确的历史对照；不得以旧“无模拟账户”说明删除当前研究流程。

分析与扫描共享 `structure`、`structure_kronos`、`structure_kronos_ma_mlp`、`structure_kronos_ma_l2` 和 `legacy_reference`。普通分析无账户；预测与模拟账户使用独立入口。来源 B/S、Kronos 采样分布与评分证据独立展示。采样频率不是校准概率，方向参考不等于目标仓位或成交。

均线 `ma_trend_v1` 使用 20 项固定有序特征，仅支持 A 版；MLP 与内嵌配对 L2 共用输入及预处理。旧 `mixed_v1` A/B 和旧简单 L2 保留原身份，不得改名成均线配对模型。界面默认值与 CLI 的历史兼容默认值分别维护，参数不得无声忽略。

## 因果、标签与资格

- `as_of` 先截断输入；结构锚点、确认时间、价格可用时间分别记录。周/月闭合使用核验日历或下一周期实际观测，不能回填未来信息。
- 新标签检查未来交易日连续性、来源、成交价格可用性、OHLC 几何、成交量/额与停牌状态。未成熟、缺数据、拒单和未完成分支分别保留，不填负类或零分。标签公式与成熟门槛不得因样本不足降低。
- 预处理只拟合训练段；校准只拟合校准段；候选选择限于训练内部。Kronos、评分模型、原生生成身份分别管理。输入、列顺序、schema、日历及实际内容 SHA 约束复用。
- 历史候选、研究账户、自动纸上用途和独立前瞻认证分开。训练完成、软件发布或目录名不赋予资格。旧参考模型的费用、8%/2R 及独立质量门槛仅按其原合同核验，不转嫁或放宽为新账户默认规则。
- 模拟成交由 Broker/Ledger 产生，保留下一核验可执行开盘、整手、T+1、费用、流动性、拒单和未清仓状态。价格与账户硬风险独立运行，缺模型不能阻塞已有库存的合规退出。
- 旧模型、账户和报告保持冻结身份；新代码不能改写原身份绕过续算限制。需要新算法时建立独立分支，不能自动升级旧账本。

## 扫描、执行与缓存

组合扫描默认每批 200 次预测、300 秒，保留完整冻结人口与全部缺失原因。续批生成新结果，只处理原结果未完成项；已处理行、人口、日期、模型、原始内容、日历或生成身份不一致时拒绝续算。占位 WAIT 不能显示成有效观望。

CPU 来源准备采用有界调度，应用 worker 上限 4，准备缓冲受限；预测和逻辑预算按冻结人口顺序消费。Kronos 在协调进程单实例运行。执行适配器独立记录身份，不能伪造原评估器或数值生成身份。存储、IPC、进程故障不得吞为单股数据失败。

时间预算从入口及前置身份核验开始，取消、到期和业务缺失分别处理。预算为协作式边界；停止新增计算后仍须完成 worker 退出、最终核验和原子保存，并报告实际耗时。取消和中断不会自动恢复。

原生状态使用显式 JSON schema/SHA/引擎身份，禁止任意 pickle。只有完整前缀、数值依赖、设置与状态核验等价时才追加；历史修订或不等价恢复只重建受影响股票。闭合分块可复用，完整事件与价格 float64 保留。未精确等价的方差近似不得启用；lossless delta 默认不替换现有缓存或冻结物理身份。

`ResearchStore` 保留不可变内容对象、多个 pin owner、跨进程配额、租约和 GC 墓碑。批量发布/租约原子完成；manifest 与所有分块 TTL 同事务核验。状态摘要的 DB/WAL 观察代次只用于失效，不替代来源实际 SHA。读取结果及板块 GET 不启动数值计算。

## 股票与板块范围

新更新、基础信息写入、搜索、分析、扫描和新增关注排除北交所别名及代码。显式沪深代码优先识别，不能误删沪市 B 股。历史读取、低层规范化和旧关注删除保持可用。

板块计算采用 `sh_sz_a_v1`，只纳入六位 `6xxxxx.SH`、`0xxxxx.SZ`、`3xxxxx.SZ`。行情矩阵、全市场分母、成员覆盖率、同业与原生聚合使用同一投影。投影另绑原快照与哈希，来源快照和上游排除证明不可改写；不完整来源或空投影不取得完整资格。

默认板块只选择核验过的新范围结果，无结果则待补齐，不回退旧混合范围。历史显式读取保留原成员和统计，明确标识原范围。当前成员不能回填历史训练；成交金额代理不能称净流入，重叠板块不能相加当市场资金。

日更核验目标日覆盖后同步板块；原行情成功不等于全部派生完成，整体可为 partial。明确无新行情不推断停牌。日更不训练、不恢复取消任务，也不隐式删除历史原始数据。

## 任务、维护与恢复

任务先持久接单再入队，记录 owner 身份、心跳、取消与提交意图；中断产物只有实际 SHA/身份匹配才能标记 recovered，不冒充任务成功。列表、统计和扫描页使用保存索引；旧结果惰性迁移不改报告字节。

终态记录删除与产物回收分开。清理必须预览精确清单，执行重验活跃状态、引用、边界和实际哈希。原始行情、必要模型、账户、关注、来源、日历父链、板块链及审计不按预览 TTL 删除。符号链接、共享硬链接、未知引用和变化后的文件保持保护。

北交所历史数据退役使用独立离线维护与回滚备份；升级和日更不自动执行。保护性恢复只写新的独立目录，逐项核验并移除未备份的临时缓存索引；缺永久保护对象则失败。恢复不授予旧账户新版本续算资格。

## 模块、设备与发行

路径由 `.env`、`core.paths` 和 RunContext 解析；状态不写 site-packages。测试隔离业务目录，不继承宿主 `.env`。冻结 CZSC 1.0.1 来源及许可证保留，未经来源核验不能替换引擎。结构与精确价格在 CPU float64；神经模型使用实际请求的 CPU/MPS/CUDA float32。明确设备不可用时必须报告，不能静默回退或推断 GPU 工作。

实现前读相关源码、配置与测试，使用 `ai_change_logger.py start/finish` 追加事实和验证。无 Git 环境记录内容清单及脱敏 diff，不初始化伪历史或补造旧起点。发行沿真实 Git 历史合并，保留已有平台修复；运行目录不得整树覆盖发行树。

公开源码和安装资产不含原始行情、模型权重、账本、秘密、主机路径、私有运行身份或用户提示词。公开 fixture 使用明确合成数据。源码、CLI/API、网页、配置和文档同步；最终同字节安装资产分别验证 Windows/Linux CPU 与 macOS CPU/MPS，未执行的平台明确待验证。历史验收不能替代本版发行证明。
